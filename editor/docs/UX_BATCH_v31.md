# UX 批次 v31 —— 卡片视图收起代码块 / 步骤复制（跨操作复用）/ 连选区间复制（2026-10-10）

编辑器 APK，`com.vtouch.editor`；APK 存档 `out/vtouch-editor-v31.apk`，装机 md5
`9881e5a6aa186dcff6f351f952d87a64`（逐字节一致；两轮构建——二轮修 chip 宽度与渲染取景）。零核心改动（全在编辑台侧）。

## 目标

用户两条：①「卡片视图也能收起代码块」（总览 v12.3 已有，卡片缺）；②「支持复制步骤——
降低重复步骤编写，提高步骤利用率」（既有多为跨方案整操作复制，缺步骤级复用）。

## 拍板口径（用户三问全按推荐）

1. **粘贴落点** = 位置对话框：「粘贴」→ 合法落点列表（快捷项：末尾 / 开头 / 同操作
   「原位置之后」；其余升序）。不采用「一键贴末尾」。
2. **变量引用** = 原样复制 + 轻提示：字段一字不改；粘贴后若检测到槽位冲突/重名/悬空/漂移
   → toast 提醒「变量引用 N 处需调整」，不自动改（自动重映射被否）。
3. **连选区间** = 做进本批：长按步骤行进入连选 → 点另一行定范围 → [复制所选]；
   块边界自动补全（选到块头 → 整块；块尾/否则/子条件 → 回所属块；子条件链随头走）。

## 实现锚点

### 1. 卡片视图收起（口径同总览，镜像实现）
- 块头行右端 **▼/▸**（40dp 热区）；收起计数 chip「已收起 N 步」挂**块尾行**（首版挂块头，
  被 4 个控件挤成两行——二轮修正；块尾行右侧空间充足且语义顺：计数落在块的收口处）。
  收起 = 块体（含子条件行/否则行/嵌套块）整体跳过，**块尾行保留**（shell 有底、[✕ 整块] 可达）。
- **收起集与总览共用**（`foldedBlocks`，按步骤对象身份；进编辑会话重置——沿用 v12.3）；
  配对失败按展开处理。
- 联动：`focusStep()` 不再限于总览——插入/移动/粘贴定位到收起块内 → `unfoldAncestorsOf`
  自动展开（v26 逻辑扩展）。
- 锚点：`OpsPage.toggleFoldAt`（总览回调与卡片 chev 共用）、卡片分支 `foldTail` 跳过、
  `blockHeadRow(…, foldN)`、`focusStep`。

### 2. 步骤复制 / 粘贴（全局单槽剪贴板）
- 剪贴板 = `StepClip`（新文件，纯逻辑、无 Android 依赖——可离机核）：单槽深拷贝；
  跨操作、跨方案存活（进程内静态；退出进程清空）；**粘完不清空**，可多处粘。
- **[复制]** 按钮：步骤行、块头行（**整块** = `unitTail`，含子条件/否则/块尾，同「移动」口径）、
  子条件行（单条；粘贴落在可挂头的链上/其他 19 后，试插入校验自动过滤）。
- **底栏 [粘贴（N 步）]**（剪贴板非空时出现）→「粘贴到…」对话框：
  - 合法性 = **试插入 + `Ops.structureErr`**（与「移动」同规则；含跳转的单元按其结构
    约束过滤——不可粘位置不列出）；超 512 拒绝（无落点 toast）。
  - 快捷项序：末尾（最常用）→ 开头 → 同操作「原位置之后」（`srcIdx+1` 合法时）；
    其余升序；标签语义 =「第 K 位」= 单元首行最终落位（同「移动」）。
  - 粘贴 = 深拷贝就地插入（多次粘贴互不影响）；成功后自动定位到新行（收起块内自动展开）。
- **预检轻提示**（原样口径）：`StepClip.preflightNotice` 对账
  ① 单元计算步槽位被目标占用（异名）/与目标重名；② 负编码引用在「目标∪单元」无名字（悬空）；
  ③ 目标槽名与源槽名不符（漂移）；④ 提示模板 `{名}` 找不到定义；⑤ 计算步表达式引用未定义名。
  有 → toast 附一句「（变量引用 N 处需调整）」；无 → 静默。
- 锚点：`OpsPage.copyOne/copySelected/buildPasteItems/pasteClipboardAt/pasteDialog`、
  `StepClip.copy/legalPositions/paste/normalizeRange/preflightNotice`。

### 3. 连选（长按进入）
- 长按任意行（步骤/块头/子条件/否则/块尾）→ 进入连选（锚点行高亮 + 底栏切
  「已选 N 步 / [取消] / [复制所选]」）；首次进入给一次提示 toast。
- 点另一行 = 定范围（块边界自动补全；破损段拒绝并保持原选择）。
- 退出：复制所选 / [取消] / 返回键 / 切视图 / 任何插入·移动·删除路径（防索引失配）。
- 锚点：`OpsPage.beginSel/extendSel/selRange/clearSel/attachRowSel`。
