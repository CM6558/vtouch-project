## 1. 对齐口径（来源：仓库 src-ui/vtouch_ui.cpp + src/vt_ops.c + src/vt_expr.c，逐字）
- **ops.conf v5**：`step <type> <a1> <a2> <a3> <a4> <ms> <ref> <j1> <j2> <expr>`（10 字段；ref/expr 空写 `-`；
  expr 取行尾整段可含空白）；序列化统一写 v5（v1..v4 读入即翻译并升级）。
- **11 类步骤**：1 点按 / 2 滑动 / 3 等待 / 4 按下 / 5 弹起 / 6 区域判断 / 7 开关判断 / 8 跳转 / **9 计算 / 10 找图 / 11 找色**。
- **变量编码**：-1..-5 触发（tdx/tdy/tux/tuy/tms）、-6/-7 fx/fy、-8/-9 退役槽、**-10..-25 自定义变量索引 0..15**。
- **计算步**：a1=变量索引（0..15）、ref=变量名（[A-Za-z_][A-Za-z0-9_]*、1..15）、expr=表达式（≤63，可解析）；
  其余字段必须 0；变量表由计算步派生、名字唯一。
- **滑动 j1/j2**：按下后停 / 弹起前停（0..60000 或变量）；ms 字面 1..60000。
- **找图**：ref=模板名（必填）、expr=区域名（空=全屏）、a1=阈值 0..255、a2=颜色校验 0/1、
  ms=持续超时 0..60000、a3/a4 档位、j1/j2 目标。
- **找色**：a1=模式（0 单点 / 1 多点）；单点 ref 必空、a2=(颜色<<8)|容差；多点 ref 必填、a2=0；
  expr=区域名；ms/a3/a4/j1/j2 同上。
- **表达式引擎**（vt_expr_check 移植）：+ - * /、括号、一元负号；atan2/sin/cos/abs/min/max/sqrt（按度）；
  长度 ≤63、嵌套 ≤8、token ≤128；静态常量折叠（除零/负数开方/非有限仅常量可判时拦）。
- **翻译矩阵**（v1..v4→v5，对齐面板 ops_translate_old）：v4 计算步（a1=槽 1..4、ref 空）→ 名 r<k>、索引按步序分配；
  字段 -6..-9 有对应 r<k> 变量则重映射 -10-索引；v1/v2 条件步成立档缺省 → 继续下一步；只翻「允许变量」字段。
