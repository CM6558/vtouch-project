# 区域画布 v13：可视化增删改 + 方向视图 + 免重启热生效（2026-10-08）

## 目标（用户口径）
「删除区域没有效果；视觉化编辑效果不好——希望可视化就能增删改；可自由切换横屏竖屏查看区域显示；
不一定要设置背景（但要保留）；选中一个区域可以进行数值调整或其它操作；保证所有操作可用、界面友好易用；
**不希望修改后还要重启核心才生效**。」

## 根因（三条，互不重叠）
1. **删除没有效果**：列表页 [✕ 删除] 只改内存 + `dirty=true`，需再按 [保存] 才写盘，且删除 toast 无任何提示
   → 用户以为删了，实际盘上没变；即便写盘，还有根因 2。
2. **免重启失效（主因）**：热生效机制 T8（面板 mtime 轮询 → `scheme_reload` 强制清空重放）在仓库树内
   （eeace02），但**设备上现役的 vtouchd_ui 是 pre-T8 构建**——对账：0d8506dc 探针「热生效」=0，
   本机树构建 274e691a=2。pre-T8 下改盘不会进核心，唯一生效路径=重启核心（面板启动回灌）。
   （佐证：/data/local/tmp/vt_ui_core.log 22:11-22:12 会话——核心启动即回灌 r1/s1/c1/c2+op1/op2，
   此后只有转屏批次写入，改盘零反应。）
3. **画布能力缺口**：无删除；无方向视图（横竖屏预览）；有帧才有画布（无帧=死路）；选中后无数值精调。

## 改动清单（编辑台 app；仓库/核心/契约零改动）
- `RegionsPage.java`：列表 [✕ 删除]（列表内 + 编辑页内两处）= **立即写盘**（backup+原子写+镜像）；

  未跑 = 「启动时生效」。保存类操作一律不再弹重启。
- `ImageView.java`：`setSpace(w,h)` 无底图空间（网格画布）；形状**裁到画面区**（屏外部分不再悬浮）；

  `regionOffCount()`；`setBgHidden` 底图开关；网格/边框绘制。

  - 选中检查器：数值格（矩形 X1/Y1/X2/Y2；圆 CX/CY/R；直填 + ±步进 + 长按连发步 10，与拖拽同口径
    =显示坐标，保存时按刚读盘基帧折算）+ [编辑属性]（id/类型/绑定/开关型——复用 RegionEdit.buildProps，
    类型转换含几何重解释）+ [停用/启用] + [删除]（确认后**立即写盘**）。
  - [保存全部] v2：回写 moved + propsDirty + 新件；改名/属性按 `origId` 对账；校验后落盘。
  - **底栏重锁**：v9.6 锁高是"打开时定高"，检查器动态出现会被裁 → 选中态变化时按当前内容重算栏高

## 口径（后续会话遵守）
- 区域显示/命中 = 基帧视口坐标（v12e 不变）；检查器数值 = **当前画布空间坐标**（帧像素或网格空间），

## v13.3 版式重排（2026-10-08 深夜，impeccable 流程）
问题（用户）：「下方的太靠下了按钮甚至看不见了；上方明明空间那么多，下方挤的要死；必须用技能设计」。
根因（证据）：画布层挂 contentWrap（壳层头部+页签之下再压 3 行 chrome）；渲染台一直以竖屏 3008px 验证 → 横屏（真机层高 ≈1200-1300px）固定总高 > 层高 → **底行被裁出层外「看不见」**。targetSdk=29 非边到边（底栏与导航条无关）；数字格输入时 IME 默认行为会覆盖底栏（清单未设 softInputMode）。
重排（impeccable scoped 改版，视觉权威 = 本 app v5.1 体系）：
① **编辑会话层改挂 root 全屏**（Shell.openLayer → root）——盖过壳层头部，竖屏额外回收约 110dp 给画面；
② 会话级操作（还原 / 保存全部）→ **顶栏右侧**（标准 Done 位）；[＋矩形 / ＋圆] → **视图行**（补上方空档）；底栏主行取消；
③ 底栏只留两态：读数行（未选中）/ 检查器（选中）；**未保存态改由 [保存全部] 亮/灰表达**（不再占检查器文字）；
④ **宽屏（≥640dp）合并帧源行与视图/工具行**（横屏共 2 行 chrome）；数值格宽屏一行放全、窄屏两列；
⑤ 清单 `windowSoftInputMode=adjustResize`（axml 编码器新增 attr 0x0101022B）——键盘弹出时窗口收缩，底栏不再被 IME 压住。
验证：测试台 **62/0**（含新「双档溢出核」）；**溢出核 = 无(竖/横)**（竖屏现布局 + 宽结构 3168×1200 压力值）；渲染件 `edit_regions.png`（竖屏三行 + 检查器）与 `edit_regions_wide.png`（横屏两行 chrome + 单行数值）目检无裁切；impeccable `detect` 结果 `[]`。
测试台新增件：`renderViewWh`（指定宽高渲染）、`assertOverflow`（溢出专用断言）、`VisualPage.wideOverrideForTest`（强制宽结构）。
