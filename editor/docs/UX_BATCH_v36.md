# UX 批次 v36：代码格式化 + 缩进（脚本编辑器）

2026-10-10 · 前置 v35（T6 双视图编辑器）· 触发：用户「需要支持代码格式化」

## 1. 口径（拍板记录）

- **[格式化] = 规范排版，不是重写语义**：每语句一行、块体 4 空格缩进、操作数空格分隔、命名参数固定序。
  **不展开默认参数**（`点按 1 2` 格式化后仍是 `点按 1 2`，不补 `50`）——默认展开属「块→脚本」生成口径（`VtFromSteps`），
  「格式化」按用户直觉只动排版。已与规格 r9 同批写死。
- **注释全链保留**（本次新增能力）：注释随属主语句上方保留；块尾注释按块 `endLine`（闭括号行）归位——
  `}` 前的注释留块内、`}` 后的注释出块外，分界精确；字符串内 `#` 不算注释。
- 侧线 `#模式` 保留（按原值）；解析失败：不动原文，错误行标红 + toast「无法格式化（第 N 行）：…」；
  已是规范形态只 toast「已是规范形态」（幂等，二跑零改动）。
- **缩进**（配套，T6.2 原列项）：回车自动缩进（沿用上一行缩进；上一行以 `{` 收尾再加一级）+
  辅助条 [缩进]/[取消缩进]（当前行或选中行整体 ±4 空格；空白不进语义，安全）。
