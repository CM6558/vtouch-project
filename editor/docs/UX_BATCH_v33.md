# UX 批次 v33（2026-10-10）—— 步骤行「＋ 在下方插入」+ 现有 ＋ 按钮语义统一

用户：「我想加个功能，在当前步骤下方添加步骤」→ 追问口径后拍板：**在步骤行上给「＋ 在下方插入」**，
并把原有 ＋ 类按钮（块头 / 否则行）语义统一、尽可能功能按钮不重复。

## 统一规则（所有「＋」= 在所在行正下方插入新步骤）

| 行的类型 | 落点（Ops.insertBelowAt） | 说明 |
|---|---|---|
| 普通步骤（含块内/未解锁无入口） | idx+1 | 新步骤落位 = 本行 +1 |
| 块头（循环 / 条件块） | 子条件之后、块体开头（clauseTail+1；需配对） | ⚠ 语义变化：原 = 块体末尾 |
| 否则行 | idx+1（否则分支开头；需在块内） | ⚠ 语义变化：原 = 否则分支末尾 |
| 块尾行（循环结束 / 条件块结束） | idx+1（整块之后） | **v33 新加键** |
| 子条件行 | 不设（非落点，链内增删在块编辑页） | — |

「加到块体 / 否则分支末尾」的新路径 = 点块内末行 / 块尾行的 ＋（效果相同）。
底栏 [＋ 添加步骤] 不变（= 整体末尾追加；空操作/常驻入口）。

## 按钮排布

- 普通步骤卡：**[＋] [↕ 移动] [复制] [✕ 删除]**——**[✎ 编辑] 退役**（整卡点击本来就进编辑=功能重复；
  且行宽只能容 4 个 flat 键，第 5 键必挤换行）。未解锁行不动（保持原三键 + 提示文字）。
- 块头行：[↕ 移动] [复制] **[＋]** [▼]（排布不变，＋ 语义改「正下方」）。
- 否则行：**[＋]** [✕ 否则]（＋ 语义改「正下方」）。
- 块尾行：**[＋]** [＋ 否则] [✕ 整块] / **[＋]** [✕ 整块]（新键排最前；[＋ 否则] 自带说明词、职能不同，不算重复）。

## 实现

- `Ops.insertBelowAt(steps, idx)` / `Ops.insertBelowCtx(steps, idx)`（纯函数；未配对块头 = -1 → 报「结构未配对（先修复再插入）」）。
- `OpsPage.addBelow(idx)`：四类行统一入口 → `askTypeThenAdd(at, ctx)` → 类型弹层 → 步骤编辑页 → [保存] 落位
  （`insertNewStep`）+ 自动定位（v26 focusStep）；[取消] = 不插入。无新增测试钩子（复用 `startNewStepForTest` / `saveStepEdit`）。
