# 编辑台 v7 视觉素材方案 —— 抓帧 / 看图器 / 模板·点集 / 本地试一下

日期：2026-10-07 · 状态：**待评审（拍板后实施）** · 范围：**仅 `~/vtouch-editor`；仓库核心/面板零改动**

> 上位口径：接替 v6 对齐案的边界条款「模板/点集文件创建属面板截帧职责」（`UI_V6_ALIGN_PLAN.md` §3）。
> 用户口径（2026-10-07 两轮原话）：取图/取色/取点要**精确控制、可编辑可查看、增删改、能测试**；

## 0. 目标

把「视觉素材」的完整编辑能力搬进编辑台：**抓帧 → 看图 → 框选/点选/吸色 → 存模板/点集 → 测试 → 在步骤里使用**，
全程 app 内闭环、不依赖核心在跑；素材落盘后**核心运行期直接可用**（核心自己读 `.tmpl`/`.pts`）。
测试分两层：**P1 本地试一下**（引擎算法 Java 直译，帧上当场出结果）+ **P2 真机试一下/试运行**（WS 控制面，另案）。

设计四尺（= 验收性）：
1. **精确** —— 一切选择在看图器上：缩放/平移/放大镜/十字线/像素级数字微调；读数 = **竖屏逻辑坐标**。
2. **全生命周期** —— 素材页（模板/点集/帧库）：缩略图、预览、编辑、改名、删除（引用检查）；步骤字段旁有深入口。
3. **能测** —— 本地试一下（命中画框 + 坐标 + 耗时 + 阈值快捷重试）；P2 真机试。
4. **不多一步** —— 入口跟使用点；帧是母版一帧多用；`[保存并试一下]` 一步；命名自动建议；历史帧免重抓。

## 3. 流程设计（六条闭环；每步为「不多一步」交账）

**① 抓帧**：目标画面里点浮标（单击 = 抓帧；拖动 = 移位；长按 = 收起）→ 进帧库。
编辑器内 `[去抓帧]`：退后台 + 浮标进**武装态**（高亮提示"点我抓帧"）→ 抓完自动回跳并打开看图器。
抓帧瞬间浮标自隐 ~150ms（自己的窗口，常规 API）。后台回跳靠既有 **SYSTEM_ALERT_WINDOW 豁免**（已授权）。

**② 看图器**（一个组件多模式复用：框选/点选/吸色/点集/预览/区域底图）：
缩放 1–8x（按钮 + 双指）、平移、放大镜、十字线、数字微调；任何选择的读数 = 逻辑坐标。

**③ 模板闭环**（对比面板现流程 ≈10 步跨 3 页 → app 3-4 步不离开步骤编辑）：
游戏抓帧(1) → 步骤字段 `[新建模板]`(1) → 框选 + 精调 → 命名（预填）→ `[保存并试一下]`(1) → 图上见命中框；调阈值秒重试 → 回步骤，字段已指向新模板。

**④ 点集闭环**：点基准色 → 点参考点（偏移自动、逐点吸色）→ 逐点容差 → `[保存并试一下]`；模糊色提示。

**⑤ 取点/吸色回填**：字段旁 `[取点]`/`[吸色]` → 图上点选（放大镜）→ 确认。同一帧可连续回填多个字段。

**⑥ 素材页**：三段 Seg「模板 / 点集 / 帧库」；行 = 缩略图 + 名 + 尺寸/点数 + 引用数；
`[预览] [编辑] [改名] [删除] [试一下]`；删除被引用素材先弹"被 X、Y 引用"（仅警告不阻断）；
`[＋新建]` 同走抓帧闭环。StepEdit 模板/点集字段旁显示缩略图。

## 4. 数据与口径对账

### 4.1 素材文件格式（逐字节；写端镜像）
- **`.tmpl`** = `"VTM1"` + ver u32=1 + w u16 + h u16 + rot u8 + res u8=0 + gray[w*h]
  + 尾扩展 `x u16 + y u16 + 平均色 r/g/b u8×3 + res u8`（8B；原区域左上 + 颜色校验存色）。
  灰度 = `vt_vis_gray_px`：`(77r+150g+29b+128)>>8`（唯一来源 `src/vt_vision.h:35-50`）。
  平均色算法逐行对齐面板写端 `vis_save_tmpl`（`vtouch_ui.cpp:7024` 起）。
- **`.pts`** = `"VTP1"` + ver u32=1 + n u16 + res u16=0 + base_rgb u32 + base_tol u16
  + n×{dx i16, dy i16, rgb u32, tol u16} + 尾扩展 x u16 + y u16（基准位置）；n ≤ 16。
- 兼容：只写 8B 尾扩展新版；旧文件照读（无尾扩展 = 无位置，重编辑走"重选基准"口径）。

### 4.2 坐标映射（逐行镜像 `src/vt_vision.c:655-703`）
- 帧 = 抓帧时**当前方向**原生像素（rot = `Surface.ROTATION_*` 0/1/2/3；竖屏 1440×3168 / 横屏 3168×1440）。
- `frame→logic`：r=1: `lx=W-1-fy, ly=fx`；r=2: `lx=W-1-fx, ly=H-1-fy`；r=3: `lx=fy, ly=H-1-fx`；r=0 原样（r∈{1,3} 时 W=fh,H=fw）。
- `logic rect→frame`：照 `vt_vis_logic_rect_to_frame`（区域限定换算用）。
- 看图器所有读数/回填一律经映射后输出逻辑坐标；框选内部按帧像素存储 + 双显。

### 4.3 抓帧链路（app 侧）
- `su -c screencap <file>`（raw）或 `screencap -p <file>`（PNG）；两种编码的**耗时/头格式/保真**由 P0-①②③ 实测裁决（缺省 raw）。
- 面板图层带 skip-screenshot 标志（`VTouchUI.java:439-446`）→ 期望抓帧天然排除面板（P0-② 验证）；浮标自隐 ~150ms 排除自身。
- 帧输出到 app 私有目录，解码后进内存；帧库保留最近 10 帧（PNG + 侧车 meta：时间/rot/显示尺寸）。

### 4.4 引用检查口径
- 扫描 `ops.conf`（live + 各 `schemes/*/ops.conf`）的 **ref 字段**（找图=模板名、找色多点=点集名）统计引用；
- 删除/改名时提示"被 X、Y 引用"（仅警告，不阻断——与面板"悬空按未命中处理"同口径）。
