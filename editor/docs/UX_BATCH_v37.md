# UX 批次 v37：输入提示（命令作用+参数 / 前缀候选补全）

2026-10-10 · 前置 v36（[格式化]+缩进）· 触发：用户「输入的时候希望有命令提示，提示作用和参数什么的」

## 1. 口径

- **提示条**（编辑器下方、辅助条上方；无提示时收起占零高）：
  - **命令态**：光标词/行首词命中命令 → 一行「词 · 作用 · 参数」——如 `点按 · 点击屏幕坐标 · 点按 x y [ms]（默认 50）`；词色=琥珀。
  - **候选态**：光标左邻词是 ≥1 个命令的前缀 → 该词列成可点小键，**点击=原地补全**（替换当前词，含词右延）。
- 回退序：光标词精确 → 前缀候选 → 行首词（光标在参数上时给语句帮助）→ 无。
- **抑制**：字符串内、`#` 注释内（含 `#模式` 侧线行）不出提示——不打扰内容写作。
- 表内容按**规范 §3/§4 抄录**（44 保留字 + 7 预定义变量 + 语境词/参数键）；改语言须同批改 `VtHelp`。

## 4. 坑

- 构造器内 `setSelection(0)` 早于提示条建好 → `updateHint` 全程 null 守卫。
- 测试建议：候选数断言用 `找`（恰 3 个：找图/找色/找色点），别用会随表增长变的词。
- `cursorEndForTest` 带尾换行文本会落「末尾空行」——行内末尾请用 `cursorToForTest(len-1)`。

## 5. v37b 增补：补全=插入参数模板（用户「是希望那种自动补全带模板的那种」）

- **候选补全 / 命令键 = 插入参数骨架**（非裸词）：
  - `点按` → `点按 100 200 50`（`100` 选中，键入即替换）；`等待` → `等待 100`；`滑动` → `滑动 100 200 300 400`；
  - 块级（`如果/当/直到/循环/函数/否则`）→ `如果 真 {\n    \n}` 形态：**体行缩进随当前行**（缩进中插入自动对齐），条件位选中；
  - 串参（`找图/找色/提示/框区域/开关开/在区域`）→ 光标落引号内；`找色点` → 色值选中；参数键 → `时长=300`（值选中）。
- 实现：`VtHelp.H` 增 `tpl/selA/selB`（`\u0001`=行缩进占位，仅出现在选中位后、不影响 sel 偏移）；`VtHelp.template(h, ind)`；`ScriptEdit.insertTemplate(h, wholeWord)` 取代 `completeWord`（候选替换光标词+右延；命令键纯插入）；新钩子 `selForTest()`。
