# OPS_PLAN_V6D —— 「提示」步骤（运行时向用户显示自定义文本：变量引用 + 拼接）

状态：**待拍板**（2026-10-09 夜；用户原话：「想在步骤里加一个用来提示用户的能力，支持引用变量，拼接字符串」）

## 1. 目标（用户口径对账）

- 新操作步骤类型 **21「提示」**：执行到该步时，在屏幕上向用户显示一条文本；文本 = 字面文字 + 变量值拼接。
- 占位语法 `{名}`：名 = 既有变量空间（tdx/tdy/tux/tuy/tms/fx/fy + 自定义变量，含中文名）；同源校验。
- 显示载体 = **面板**（原生 ImGui 悬浮层，运行时唯一常驻 UI）：顶部居中浮层、深底白字、到时淡出；同屏一条、新覆盖旧。

### 能力对账表

| 想要的 | 现状 | 本批 |
|---|---|---|
| 步骤能「提示用户」 | 日志/事件环只有事后可查，运行中用户看不见 | 类型 21：核心渲染文本 → SHM → 面板浮层 |
| 引用变量 | 表达式引擎已有完整变量空间（v10/v11） | `{名}` 占位，同一名字表 |
| 拼接字符串 | 无字符串设施 | 字面 + 占位值按序拼接；`{{`/`}}` 转义 |

## 2. 不可协商项对账

- **行格式不变**：step 行仍 10 字段；模板文本放 `expr` 尾字段（自由文本含空格 = 既有读端口径 ✓）；新类型号 21（旧核心按条拒收、面板对未知类型行原样回写零改动）。
- **契约**：`VT_SHM_VERSION` 13 → 14（状态块加提示通道：`toast_seq` + `toast[256]`）；两侧同一二进制重建（devbuild）。
- 提示 = **非阻塞**：显示后立即继续下一步（同计算步的单拍语义）。
- 长度：模板 ≤ **63 字节**（复用 `expr[VT_EXPR_MAX+1]` 槽；≈ 20 个汉字 / 63 ASCII）。渲染后文本 ≤ 255 字节（溢出截断，防御）。
- 兼容矩阵：新编辑器+旧核心 = 该操作被拒（升级即好）；旧编辑器+新核心 = 行原样保留；无面板 = 提示静默丢弃（不中止）。

## 3. 设计

### 3.1 数据（类型 21）

- 字段：a1..a4 / j1 / j2 = 0；ref = 空；**expr = 模板（必填）**；ms = 显示时长（0..60000，0 = 默认 2000）。
- 校验（`vt_ops.c:380` switch 加 case 21；`:683` 附近镜像；`:758` note 更新）：
  - 模板非空、字节 ≤63；占位 ≤16 个；
  - `{` 必须配对（不配对 → `模板错: 未闭合的 {`）；
  - 占位名 ∈ 变量空间（预置 7 + op->vars）否则 `模板错: 未知变量 <名>`；
  - 其余字段 0/空（ms 除外）否则 `字段必须为 0`。

### 3.2 运行时（`op_begin_step` `vt_ops.c:2042` 加 case 21）

- 逐段渲染：字面照抄；占位取值（预置按 trig/res 掩码、自定义按 vmask；值 = llround + int 夹取，同计算步日志口径）→ 十进制拼接；`{{`/`}}` → `{`/`}`。
- 无值口径（拍板①）：触发变量缺 → 中止 `变量无值`；fx/fy 未命中、自定义未写 → 中止 `结果无值`（与表达式一致；替代方案见拍板表）。
- 写区 A：`toast` 文本 + `toast_seq++`（release）；面板不在/无 SHM 静默跳过。
- 日志：`op 提示 <渲染后文本>`（恒打）；单拍 → `PH_WAIT` 顺延。

### 3.3 显示（面板）

- `ui_glue.c` 加 accessor（对照试查 `vt_shm.h:239` 模式）：`vtouch_toast_seq()` / `vtouch_toast_take(buf, cap)`（acquire 读 seq vs 本地 seen）。
- `vtouch_ui.cpp` 主循环：新 seq → 记录显示窗口（单调钟 + ms）→ 前景绘制顶部居中浮层（`GetForegroundDrawList`；先例 `:2363`/`:3152`）；末 300ms 淡出；文本变化时 `ui_glyph_scan(text)`（动态字形防豆腐块，`:2169`）。
- 样式（拍板③）：深底（黑 ~70%）白字、圆角、顶部居中（y ≈ 屏高 12%）。

### 3.4 编辑器（~/vtouch-editor）

- `Ops.java:27` 加 `T_TOAST = 21`；`typeName :43`「提示」；parseStep 透传闸 `> 20` → `> 21`；validate 镜像模板校验（同核文案）；summary = `提示 · <模板（截断）>`。
- `StepEdit.java:38` TYPE_NAMES/TYPE_IDS 加「提示」；build case：模板 Text 字段 + **[插入变量]**（复用变量列表 → 光标插入 `{名}`）+ 时长 Num「显示时长 ms（0 = 默认 2 秒）」+ 说明行 + **实时预览行**（占位按示例值展示拼接效果）。
- `Forms.java:471` typeSheet 加条目（说明一行）。

### 3.5 文案与可发现性（随批小项）
