## Task 7.1 — 「试一下」+ 屏幕标记（③）

**产出**：找图/找色步骤编辑子层 + 模板页各加「试一下」按钮：按一下 → 当场执行一次查找 → 显示结果 + 屏幕上标出命中位置。

**点**：
1. **契约 v9**（`VT_SHM_VERSION` 8→9）：帧区（区 D）头部新增测试块（面板写请求 / 核心写结果，单请求在途）：
   `test_req_seq(u32)` / `test_kind(u8：0=找图 1=找色单点 2=找色多点)` / `test_ref[16]`（模板/点集名）/
   `test_region[16]`（区域名，空=全屏） / `test_a1(i32：找图=阈值 / 找色=模式)` / `test_a2(i32：找色单点=打包色容差，其余 0)` /
   `test_res_seq(u32)` / `test_x(i32)` / `test_y(i32)` / `test_err(i32：0=命中 -1=未命中 其余=错误码，词表同 op 中止词)`。
   写端内存序照区 D 既有口径（参数先写、seq 最后 release；读端 acquire）。
2. **核心**（`vt_ops.c`，VT_UI 守卫内）：从 `op_vis_run` 抽出公共 `vis_exec_find(...)`（请求帧→等待→prepare→区域换算→匹配；**op 路径行为逐字不变**，评审逐字对比）；主循环每轮读 `test_req_seq` vs 本地 seen → 新请求则执行 → 写结果（x/y/err，release `test_res_seq`）。
3. **面板**（`vtouch_ui.cpp` + `VTouchUI.java` 不需要动）：按钮点击 → 填参数 → release 写 `test_req_seq` → 写唤醒 pipe（同编辑邮箱口径）；UI 每帧轮询 `test_res_seq`（≤10ms）→ 显示「命中 (x, y) / 未命中 / 原因」；等待超时 1.5s → 「超时（无响应）」。
4. **屏幕标记**：命中 → 画**方框 + 坐标文字**（找图 = 模板 w×h 经 c2p 映射；找色 = 固定 80×80），2s 消退 —— 复用取点「捕获标记」样式（`vtouch_ui.cpp:2119-2131` 同款）。
5. 默认（无面板）构建：零泄漏；`vt_ws.c` 等零改动。
6. 日志（核心）：`vis 试查 找图 <模板> 命中 x,y (耗时 ms)` / `vis 试查 … 未命中` / `vis 试查 … 失败 <原因>`。

**验收**：编译门（默认核 md5 逐字节不变 / ui rc=0 / real rc=0 / funcdoc 0/0）+ 静态对账；真机 E2E 在部署后（控制方直做）。

## Task 7.2 — 截帧选择器升级（④）

**产出**：模板/点集采集层（`vtouch_ui.cpp` 采集覆盖层）交互升级 —— 缩放/平移 + 可拖拽调整的选择框 + 精细选择 + 选完可回看再编辑。

**点**：
1. **缩放**：`[＋] [－] [适应]` 按钮（步进 0.25，范围 1x..8x；锚点 = 画面中心）；**平移**：拖拽画面（缩放 >1x 时）。
2. **选择框**：四角手柄拖拽调整（手柄命中半径 ≥ 24px 屏距）、框内拖动整体移动；约束在图内；最小 8×8。
3. **已选态**：确认后框保留、可继续调整再确认；模板模式保留既有「重新截帧」（取消重进的口径作废，改为直接按钮）。
4. 不动抓帧协议/不动共享内存；纯面板。
5. 屏距口径：所有命中/手柄按**当前屏**像素，绘制坐标经既有 p2c/c2p 口径（选择框本身在采集层内，直接用画面坐标即可）。

**验收**：编译门 + 真机手感（用户）。

**点**：

   左 ~60%：**步骤列表**（主区，整高滚动）；右 ~40%（自上而下）：名字行 / 门控·自动关行 / **加步区（3 列 × 4 行竖排）** / 头排 `[预览] [收起]` / 底部 `[取消] [完成]`。
2. **竖屏**：步骤列表在上（主区撑满剩余高），加步区 4×3 紧凑置底（现状保持但收紧行高），头排/底排照旧。

**验收**：编译门 + 真机（横竖屏各看一遍）。

## Task 7.4 — 持续查找 + 超时（⑥）

**产出**：找图/找色支持「持续查找」：设置超时时间，循环抓帧查找到命中或超时；命中即停、返回坐标。

**点**：
1. **字段**：复用 `ms` 列 —— 找图/找色 `ms=0` = 单次（现状）；`ms>0` = 持续查找超时（1..60000）。核心 `op_valid` 同步放宽（原「ms 必须 0」改 0..60000）。
2. **核心**（`vis_exec_find` 加模式）：持续 = 循环 { 请求帧 → 匹配 → 命中 break } 到 deadline；命中 → 成立档 + 写 fx/fy；超时 → 不成立档（未命中）。尝试计数 + 耗时进日志：
   `vis 找图 <模板> 持续 <ms> 命中 x,y（尝试 N 次 / 耗时 M ms）` / `… 未命中（超时 <ms>，尝试 N 次）`。
3. **面板**：找图/找色子层加「持续查找：开/关」+ 超时 ms 格；校验同步。
4. **面板抓帧侧**（`VTouchUI.java`，② 的延伸）：**自动保持隐藏** —— 抓帧后不立即恢复；150ms 内再来请求 → 复用隐藏态（省 40ms 沉降，~60fps 搜索）；150ms 无请求 → 自动恢复。单次查找 = 面板隐藏总时长 ~200ms（可接受）。

**验收**：编译门 + 真机（持续查找命中即停 / 超时路径 / 面板闪烁可接受）。

## Task 7.5 — 字段值四态 + 自定义命名变量（⑦⑧）

**产出**：所有数值/坐标字段直接支持计算（内联表达式）；计算步骤保留；变量可自定义命名（不再固定 r1..r4）；找图找色/按下弹起等系统预置变量名，编辑时可引用。

**点**：
1. **变量空间**：
   - 预置：`tdx/tdy/tux/tuy/tms`（-1..-5，触发数据，不变）+ **`fx/fy`（-6/-7）= 最近一次找图/找色命中坐标**（视觉步改写 fx/fy，**替代 r1/r2**）。
   - 自定义：≤16 个，名字 `[A-Za-z_][A-Za-z0-9_]{0,14}`（1..15 字符，含 NUL 的 char[16]），由计算步创建；编码 **-10..-25 = 表索引 0..15**。
2. **契约 v10**（T7.1 已占 v9）：`vt_op += char vars[16][16]`（+256B；容量核验：现 `vt_op` 3624B + 256B = 3880B ≤ 区 B 4096 断言；**若实测不过，vars 降为 12 或 8 个，按断言裁决并记录**）。计算步：`a1` = 变量索引、`ref` = 变量名（显示/日志）。
3. **计算步语义**：`<名> = <表达式>`；同名重复赋值 = 后者覆盖；引用未写 → 结果无值（沿用）。
4. **⑦ 内联计算**：字段编辑器加 `[表达式]` 模式 —— 确认时**自动在该步前插入** `计算 <自动名> = <表达式>`（自动名 `e1` 递增、可改名）并把字段指向该变量。步骤列表可见生成的步骤（「计算的步骤保留」字面满足）。
5. **ops.conf v5**：step 行不变（10 字段）；计算步 `ref`=变量名、`a1`=索引；字段负数照写（含 -10..-25）；**读端兼容 v1..v4**：v4 计算步（a1=1..4 槽、ref 空）→ 名 `r<k>`；v4 字段 -6..-9 → 重映射到对应 `r<k>` 变量索引（v4「找图写 r1/r2」的用法：新模型 fx/fy 恰好承接 -6/-7 同值语义）。
6. **面板**：数字键盘加 `[数值]/[变量]/[表达式]` 三模式；变量列表 = 预置 7 + 自定义（动态从计算步收集）；计算步编辑：名字可编辑（默认 `v1/v2…`）+ 表达式（沿用现有表达式子层）。
7. **日志**：`op 步 k/n 计算 <名> = 值`；TRACE `op 变量` 行扩 fx/fy；中止词不变。
8. **说明页 + README/AGENTS 同步**（文案先行，spec 唯一来源）。

**验收**：编译门 + 静态对账 + 真机（内联表达式自动插步、命名变量引用、旧 v4 数据兼容加载）。

## T7.7 编辑器体验轮（2026-10-05，用户四项）

1. **表达式变量列表**：表达式子层（计算步 + 字段内联两种模式）显示框右侧新增 **[变量]** 键 —— 点开 = 全变量列表
   （预置 7 中文名（点一条插入英文名）+ 自定义 ≤16，双列网格），点一条 = 名字插到表达式末尾；chips 行照旧（含预置 7）。
2. **模板重编辑**：模板页每行新增 **[编辑]** —— 读已存 `.tmpl` → 灰度合成 RGB 预览（「再次查看」）→ `[重新截帧]`
   从当前屏幕重选（恢复上次框位置；新格式文件才有）→ `[确认]` 保存：不改名 = 覆盖（`g_vis_overwrite` 放行）、
   改名 = 另存为新模板。
   - **`.tmpl` 尾扩展**：灰度后追加 `x u16 + y u16`（原区域左上；ver 保持 1）—— 核心读端读满灰度即停、忽略尾部
     （双向兼容）；面板按文件尺寸识别有无。点集（`.pts`）暂不重编辑（只存相对偏移、无绝对位置）。
3. **试一下阈值快捷调整**：找图/找色单点参数层 `[试一下]` 上方一行 `[−10][−1][值][＋1][＋10]`（找图 = 阈值 `a1`、
   找色单点 = 容差 `a2` 低 8 位；多点无）；点一下立即重试。模板页顶部同款行（`g_vis_tmpl_tol`，默认 8）供列表
   `[试一下]` 用；矮屏与上方行相撞则不画。
4. **步骤移动模式**：步骤行 `[↑][↓]` 换成 **[移动]** —— 进入移模式（整行 = 放置目标「↓ 放这里（第 N 位）」，
   其它按钮全隐防误触）；点目标行一步到位（`ope_move_to` 复用 `ope_move` 逐步挪，ref/expr 跟着走）；移动中行 =
   「移动中：第 N 步 · 点此取消」。`[移动]` 取代两枚小键 ⇒ 行内按钮更少、更不易误触。
