## §1 条件步分支（区域判断 / 开关判断同款）

### 1.1 两侧对称四档

判定结果分「成立 / 不成立」两侧，**各自**选接下来做什么（可以只配一侧，另一侧走默认）：

| 侧 | 可选项 | 新步默认 |
|---|---|---|
| 成立（区域判断：点 ∈ 区域；开关判断：区域开着） | 继续下一步 / 跳过下一步 / 跳到第 N 步 / 中止 | **继续下一步** |
| 不成立 | 继续下一步 / 跳过下一步 / 跳到第 N 步 / 中止 | **中止**（= v2 老行为） |

档位枚举（契约值，§6.2）：`OP_COND_ABORT=0 / OP_COND_SKIP=1 / OP_COND_CONT=2 / OP_COND_JUMP=3`。
跳转目标取值：**0 = 结束（直接完成操作）、1..步数 = 目标步骤**（与 §2 同款）。
v1/v2 老文件的不成立档直读（0=中止、1=跳过）不变；成立档老文件无字段 → 读入时置「继续」。

### 1.2 执行语义

- **求值失败**（变量无值 / 区域不存在 / 非开关型）→ 照旧中止，**不进分支**（判定不了 ≠ 判定为假）。
- 干净结果 → 按该侧档位执行：
  - **继续**：`PH_WAIT`，下一拍进下一步（现状）。
  - **跳过**：`R.step` 额外 +1（跳过的那一步不执行也不求值；越过末步 = 正常完成，承 v2 口径）。
  - **跳转**：目标 0 = 结束 → `op_finish()`（正常完成；收尾释放 / 自动关照走；不占跳转计数）；否则过跳转守卫（§2.3）→ `R.step = 目标-1`（正常推进 +1 落在目标）。
  - **中止**：不成立侧原因 `条件不成立`（承 v2）；成立侧原因 **`条件中止`**（新词）。
- 单位：条件步仍是**单拍**动作（同 v2：判定后本拍结束）。

### 1.3 日志

- **不成立：恒打** —— `op 条件 <区域判断|开关判断> <ref> 不成立 → <继续下一步|跳过下一步|跳到第 N 步|中止>`（覆盖 v2 两值 + v3 两值）。
- **成立：档位 ≠ 继续才打** —— `op 条件 … 成立 → <跳过下一步|跳到第 N 步|中止>`。
- 锁纪律承 v2：`region_lock` 之外记日志。

### 1.4 校验（op_valid v3）

- 两档位 ∈ 0..3；档位 = 跳转 → 该侧目标 ∈ 0..步数（0 = 结束）；其余档位的目标**忽略**（不校验、不拒收）。

## §2 跳转步

### 2.1 类型与参数

- `OP_STEP_JUMP = 8`；参数 = **目标**（**0..32**：0 = 结束、1..32 = 目标步骤），存 `a1`；缺省 1。
- 面板加步第二行变四格：＋弹起 / ＋区域判断 / ＋开关判断 / **＋跳转**。

### 2.2 执行

- 走到该步：目标 0 → 直接 `op_finish()`（正常完成、不占计数）；否则过守卫 → `R.step = 目标-1` → `PH_WAIT`（下一拍正常推进落在目标）。
- 前跳 = 跳过中间步骤；**后跳（向上）= 循环**（如跳回第 1 步重来）；目标 = 自身 = 自环（守卫兜底，不做保存期特判）。

### 2.3 防死循环守卫

- 单次运行**跳转计数**（条件跳转 + 跳转步共用一枚），起跑清零；上限 `VT_OPS_JUMP_MAX = 200`。
- 超限 → 中止 `原因=跳转超限`（走既有中止机制）。
- 「结束」使运行**正常终止**：不占跳转计数、不判上限。
- 每跳日志：TRACE 级 `op 跳转 <名> 第 A 步 → 第 B 步`（默认零输出，承 L9；VTOUCH_OPS_TRACE=1 才开）。

### 2.4 校验与漂移

- op_valid：目标 ∈ 0..step_count（0 = 结束）。
- 操作 [完成]（保存）预检：目标 ∈ 0..当前步数（0 = 结束），超界拒收 + 就地提示。
- 编辑插 / 删步骤会让目标号漂移：保存时面板校验、核心加载与起跑再校验（照旧「核心为准」；拒收走 `ops_load_put` 既有可见日志）。

## §3 坐标同编与取点填对

### 3.1 参数弹层重做（全字段一屏）

- 打开 [参数]：该步**全部数值字段一次性列出**（点按 3 格 / 滑动 5 格 / 等待 1 格 / 按下 2 格 / 区域判断 2 格 / 跳转 1 格 / 弹起 0 格 = [参数] 照旧不显示）。
- **点格子 = 激活该格**；数字键盘编激活格；[变量] 切激活格（该格可变量时）；[取点] 在激活格是坐标格时可用（§3.2）。
- **本地缓冲**：进层快照全部字段 → 层内编辑都进缓冲 →
  - **[完成]**：全字段校验**全过才一次落**（任一不过：提示该格 + 停留）；
  - **[取消]**：**全丢**（含取点回填、变量切换）。
- ⚠ 对 v2 的语义变化：v2 是逐字段 [确定] 即时落、[取消] 只停当前格；v3 改为原子落 / 全丢。老操作数据无影响（只是编辑手感）。
- 条件步的 [参数] = 判定点 x/y 两格；**档位与跳转目标是行内控件**（§1.1 两枚循环钮；档位 = 跳转时该侧出现目标格，显示「第 N 步」或「结束」，点它开键盘编 0..32）。
- 跳转步的 [参数] = 1 格「目标」（0 = 结束）。

### 3.2 取点一次填一对

- 坐标对 = (x, y)（点按 / 按下 / 区域判断判定点）或 (x1,y1) / (x2,y2)（滑动）。
- **[取点] 结果把激活格所在的那一对两格同填**（字面值；变量态被打断时照旧切回字面）。
- 十字标记 + 坐标文字照旧（T3.2）；日志 `取点 回填 第 N 步 参数 x,y = a,b`。

## §4 编辑层整屏 + 取点自动收起

### 4.1 整屏

- **操作编辑覆盖层及其子层**（参数 / 变量 / 区域列表 / 名字键盘 / 预览）按**当前屏全覆盖**绘制 —— 不再局限面板窗口（面板主窗口与列表页 / 区域页不变）。
- 吞触摸矩形（`vtouch_ui_publish_rect`）按状态切换：
  - 编辑层打开 → **全屏**（编辑时不让误触漏进游戏）；
  - 编辑层关闭 → 面板窗口（现状）；
  - 编辑层收起（取点收起 / 手动收起）→ **底部收起条**那一小块（其余整屏可点；取点收起时 = 取点落点）。
- 转屏口径承 v1：绘制与命中用当前屏坐标，`p2c` 逆变换由胶水做。

### 4.2 取点自动收起

- 进入取点态：编辑层整体收成**底部提示条**：「点屏幕上目标位置 · 点这里取消」。
- 结果回填 → **自动弹回**编辑层（参数层还开着，值已填好）。
- 取消：点提示条（走既有 `vtouch_pick_cancel` + 退出取点态）；核心 20s 超时兜底 —— 面板**自带同长计时**，超时自动退出取点态并弹回。

### 4.3 手动收起

- 编辑层头部留 **[收起]** 钮：收成条（编辑状态全部保留），点条再展开 —— 需要一边看游戏一边改时用。
- 与取点收起共用条渲染；区别：手动收起点条 = 展开，取点收起点条 = 取消取点。

## §9 说明页 v3（面板文案唯一来源 = 本节；全量 13 条）

1. 触发：给区域绑一条操作；手指碰到这个区域就会跑那条操作。
2. 时机·按下：手指碰到区域的那一刻就跑。
3. 时机·完整按压：手指碰到、抬起后跑（按一下、抬起来，才算数）。
4. 开关型：把区域当开关——每完整按压一次，「开/关」翻转一次（绿色 = 开）。
5. 门控：操作的门禁——绑一个开关型区域，它开着，操作才允许跑。
6. 跑完自动关：操作正常跑完后，自动把门控开关翻回「关」。
7. 取点：点 [取点]，然后去屏幕上点一下——那个坐标对（x 和 y）一次填进正在编辑的位置，并在屏上标一下。
8. 变量（触发数据）：这次触发的那根手指——触发按下x / 触发按下y（按下位置）、触发弹起x / 触发弹起y（抬起位置）、触发时长（按下到抬起的毫秒数）。「完整按压」触发时全都有； 「按下」触发只有按下位置；面板手动运行没有。
9. 按下 / 弹起：两条分开的步骤——按下 = 按住不放；弹起 = 松开。中间可以夹「等待」「判断」。
10. 区域判断：检查一个点在不在某个区域内；成立 / 不成立两侧各选接下来做什么：继续下一步、跳过下一步、跳到第 N 步、中止（可以只配一侧，另一侧走默认）。
11. 开关判断：检查某个开关型区域现在是不是「开」；成立 / 不成立两侧的选项同「区域判断」。
12. 中止原因速查：变量无值 / 槽占用 / 未按下 / 区域不存在 / 非开关型 / 条件不成立 / 条件中止 / 跳转超限。
13. 跳转：直接跳到指定步骤继续——往前跳 = 跳过中间步骤；往后跳 = 循环（比如跳回第 1 步重来）。目标也可以选「结束」直接完成操作；单次运行跳转超过 200 次会自动中止（防死循环）。
