# 操作编辑器 v2 设计（变量 / 按下弹起 / 条件步 / 取点提示 / 说明页）

> 状态：2026-10-02 与用户逐条对齐；**D1-D6 已按推荐拍板**（§11）。
> 本文件 = 设计定稿（待用户审阅）；实施计划另文（`docs/OPS_IMPL_PLAN_V2.md`），本文件只定义「做成什么样」。
> 口径（承 v1）：事实以现读代码为准（行号会漂）；核心改动守 **VT_UI 纪律**（默认构建零泄漏）；
> 单文件交付不变；**WS 协议一字不改**；老链路（AutoJs 客户端 / 区域事件 / 订阅）保留不删。

## §0 需求 → 特性映射

| 用户原话 | 落成 |

新增原则：其余一切不动（上口径）+ YAGNI（§10 不做清单）。

## §1 变量系统

### 1.1 变量表（运行内只读，共 5 个）

| 代号 | 界面名 | 含义 |
|---|---|---|
| `tdx` | 触发按下x | 触发这次操作的那次按压的**按下点 x**（竖屏逻辑坐标） |
| `tdy` | 触发按下y | 按下点 y |
| `tux` | 触发弹起x | 抬起点 x |
| `tuy` | 触发弹起y | 抬起点 y |
| `tms` | 触发时长 | 按下→抬起的毫秒数 |

### 1.2 来源与可用性

- **区域触发·完整按压**：5 个全部有值（抬起已发生、数据在投递前算好）。
- **区域触发·按下**：只有 `tdx/tdy`（抬起尚未发生，`tux/tuy/tms` 无值）。
- **面板手动运行**：全部无值。
- 运行中**不回填**：起跑瞬间快照，之后本次运行不再变（同 v1「整条快照」口径）。

### 1.3 使用规则（D6）

- 步骤的数值字段（坐标 / 时长）可引用变量；字段值恒为「字面数」或「变量引用」二选一。
- 引用**无值**变量 → 运行到该步时中止：`op 中止 … 原因=变量无值`（不静默当 0）。

### 1.4 操作数编码（契约内表示）

- 字段**负数**编码变量：`-1=tdx  -2=tdy  -3=tux  -4=tuy  -5=tms`；字面值恒 ≥0（坐标/时长天然非负）。
- `op_valid`：仅对「允许变量的字段」（见 §2.1）放行 `[-5, max]`，其余字段照旧拒负值。

### 1.5 数据通路（现读代码为准）

- **区域线程**：按下命中时记录该槽的 (x, y, t)；抬起结算（`r_trig_latch` 消费处）把
  按下点、抬起点（当次坐标）、时长（t_up − t_down）一并投递。
- `TRIGPEND` / `ptrig[]` 载荷扩字段；投递函数 `vt_ops_trigger_post` 同步扩参。
- **触发槽**（`struct vt_state`，现 `op_trig_seq/name/slot`）增：`mask`（哪些变量有值）+
  `dx dy ux uy ms`；消费端 `op_consume_trigger` 同轮读全（release/acquire 序照旧）。
- **执行器起跑**把变量快照进私有内存（R）；运行中改表 / 再触发不影响本次（v1 快照口径）。

## §2 新步骤类型（按下 / 弹起）

### 2.1 步骤表（v2 全 7 种）

| 码 | 名 | 字段（a1 a2 a3 a4 ms ref） |
|---|---|---|
| 1 | 点按 | a1,a2 = x,y；ms = 按住时长（a1,a2,ms 可变量） |
| 2 | 滑动 | a1..a4 = 起终点；ms = 时长（全可变量） |
| 3 | 等待 | ms = 时长（可变量） |
| 4 | **按下** | a1,a2 = x,y（可变量）；按下并保持 |
| 5 | **弹起** | 无字段；松开当前按住的手指 |
| 6 | **区域判断** | a1,a2 = 点（可变量）；a3 = 不成立行为（0=中止 1=跳过下一步）；ref = 区域 id |
| 7 | **开关判断** | a3 = 不成立行为；ref = 区域 id（须开关型） |

### 2.2 按下 / 弹起语义与安全（D4）

- 用**起跑时挑定的那个虚拟槽**（v1 已有「挑第一个空闲槽」逻辑）；按下 = down 并保持，弹起 = up。
- 弹起时若没有按住的手指 → 中止（`原因=未按下`）。
- **按住期间**只允许：等待 / 区域判断 / 开关判断 / 弹起；出现 点按 / 滑动 / 按下 → 中止（`原因=槽占用`）。
- **收尾兜底**：正常完成 / 中止时若还按着 → 自动松开 + 日志 `op 收尾 松开`。
- **帧窗纪律延续**：所有 virt 写（含按下/弹起/收尾释放）统一走既有冻结/推迟机制 ——
  不变式「执行器任何路径不在帧窗内写 `g.virt`」继续成立。

### 2.3 时长字段也可变量

- 点按 / 滑动 / 等待的 ms 允许引 `tms`（例：按住「刚才那次按压的时长」）。

## §3 条件步（区域判断 / 开关判断）

### 3.1 区域判断

- 判定 = 复用 `region_hit(rg, x, y)`（已是平坦函数：矩形含边界、圆用半径平方 64 位比较）。
- 点来源：取点 / 字面 / 变量，与其它步骤同款。
- 编辑期只查 ref 的长度/字符集（同 `vt_id_ok` 尺子）；存在性不校验、允许悬空。
- 区域不存在 → 中止（`原因=区域不存在`）；存在但**停用** → 命中恒为否（`region_hit` 语义，走不成立行为）。

### 3.2 开关判断

- ref 区域必须 `kind==toggle`（否则中止 `原因=非开关型`）；成立 = `toggle_on==1`。
- 读表纪律：**持 `region_lock` 判定、解锁后记日志**（照门控检查的现成模式，锁内不做 I/O）。

### 3.3 不成立行为（D1）

- **中止（默认）**：先记 `op 条件 <区域判断|开关判断> <ref> 不成立 → 中止`，再走中止机制（`原因=条件不成立`）。
- **跳过下一步**：记 `op 条件 … 不成立 → 跳过下一步`，步序额外 +1（跳过紧随其后的那一步）。
- 边界：末步跳过 → 等于正常完成；跳过的那一步**不执行也不求值**。
- 完整 if/else 分支**不做**（§10）。

## §4 取点增强

- **捕获标记**：取点成功后，面板在捕获点画 ~2 秒的十字 + 坐标文字（竖屏逻辑 → 当前屏换算，
  复用区域轮廓的现成换算）；字段回填与日志 `取点 捕获 x,y` 照旧。
- **适配新步骤**：取点填充「当前编辑的坐标格」——按下 / 区域判断等新步骤复用同一 [取点] 按钮。
- 标记是**纯绘制**：不参与命中、不吞触摸、不写共享内存。

## §5 说明页（术语表；面板文案唯一来源）

左侧菜单新增「说明」页，逐条白话（实施时按此文案落地）：

1. **触发**：给区域绑一条操作；手指碰到这个区域就会跑那条操作。
2. **时机·按下**：手指碰到区域的那**一刻**就跑。
3. **时机·完整按压**：手指碰到、**抬起后**跑（按一下、抬起来，才算数）。
4. **开关型**：把区域当开关——每完整按压一次，「开/关」翻转一次（绿色 = 开）。
5. **门控**：操作的门禁——绑一个开关型区域，它**开着**，操作才允许跑。
6. **跑完自动关**：操作正常跑完后，自动把门控开关翻回「关」。
7. **取点**：点 [取点]，然后去屏幕上点一下——那个位置填进正在编辑的坐标格，并在屏上标一下。
8. **变量（触发数据）**：这次触发的那根手指——触发按下x / 触发按下y（按下位置）、触发弹起x /
   触发弹起y（抬起位置）、触发时长（按下到抬起的毫秒数）。「完整按压」触发时全都有；
   「按下」触发只有按下位置；面板手动运行没有。
9. **按下 / 弹起**：两条分开的步骤——按下 = 按住不放；弹起 = 松开。中间可以夹「等待」「判断」。
10. **区域判断**：检查一个点在不在某个区域内；不满足时按你选的来：中止、或跳过下一步。
11. **开关判断**：检查某个开关型区域现在是不是「开」。
12. **中止原因速查**：变量无值 / 槽占用 / 未按下 / 区域不存在 / 非开关型 / 条件不成立。

## §6 契约 v4 → v5

### 6.1 布局增量（按 sizeof 生长，头部记录偏移 —— 双方都按头部走）

- `struct vt_step` 增 `char ref[REGION_ID_MAX + 1]`（条件步的区域引用）：24 → 40 B。
- `struct vt_op` 随动；操作表 16 条预计 +8 KB（32 步 × 16 B × 16 条）。
- 触发槽（`struct vt_state`）增 6 字段（mask + 5 数据）。
- 区 B 断言复核：编辑载荷 `struct vt_op` 变大，`_Static_assert(sizeof(struct vt_shm_b) <= 4096)`
  预计仍过（~1.5 KB ≤ 4 KB），构建期会强制核对。
- **`VT_SHM_VERSION` 4 → 5**；「v4 后布局不再变」的承诺**有意打破**（新功能需要字段；版本门照旧拒混配）。
- 尺寸预估：区 A 24576 → 32768 B（页对齐生长）、total 40960 → 49152 B；实测值在各任务报告里记录。

### 6.2 ops.conf v2

- 头 `#vtouch-ops v2`；`step` 行固定 7 字段：`step <type> <a1> <a2> <a3> <a4> <ms> <ref>`，ref 空写 `-`。
- 变量 = 负数照写（如 `-1`）；不成立行为存 a3。
- **读端兼容 v1**（6 字段：ref 缺省空、a3 缺省 0）；写端只写 v2。
- 只补缺 / 坏行单跳 / 面板编辑后存 —— 同 v1 口径不变。

## §7 面板编辑器

- 步骤类型选择器扩为 7 种；每种显示各自字段（§2.1）。
- 坐标 / 时长格：「值 ↔ 变量」切换（变量按中文名列出 5 个）；显示为中文名而非负数。
- 条件步：区域下拉（读区域表实时列表）；开关判断的列表**只列开关型**（运行时仍校验，双保险）；
  不成立行为二选一（中止 / 跳过下一步）。
- 按下 = 坐标格；弹起 = 无字段。
- 校验提示沿用既有机制（核心 `op_valid` 的 why 全量透出）。

## §8 日志增量（承 v1 §8 口径）

- 新增（默认可见，低频）：`op 条件 <词> <ref> 不成立 → <中止|跳过下一步>`、`op 收尾 松开`。
- 中止原因词新增：`变量无值` / `槽占用` / `未按下` / `区域不存在` / `非开关型` / `条件不成立`。
- TRACE 级（`VTOUCH_OPS_TRACE=1` 才开）：起跑时一行 `op 变量 tdx=… tdy=… tux=… tuy=… tms=…`。
- 其余高频明细照旧默认不打。

## §9 测试清单

- **宿主仿真**：变量编码边界（-1..-5 合法、-6 拒）、按下/弹起状态机（含异常序：未按先弹、
  按住中点按）、条件判定（矩形/圆/开关/不存在/非开关型）、跳过下一步边界（末步、连续）、op_valid v2。
- **真机**：按下→等待→弹起（按住效果）；完整按压触发 + 变量（操作直接点「触发点」）；
  区域判断（触发点 ∈ 某区域）；开关判断 + 门控联动；取点标记可见；说明页可读；
  v1 遗留两小项（运行中停止、取点面板内取消）；终态构建重部署（顺测 su 更新路径）。
- **门**：照 v1 全链（双构建 / funcdoc / pack / ci_check + md5 记录）。

## §10 不做（YAGNI，留口）

完整 if/else 与循环；取点存通用变量（p1/p2）；多指操作；按下模式触发提供弹起数据（运行中不回填）；
触发区域名变量；变量运算（加减乘除）；跟手 / 轨迹复刻；跨操作变量。

## §11 拍板记录（2026-10-02，用户「D1-D6 按推荐走」）

- **D1** 条件不成立：中止（默认）/ 跳过下一步（每步可选）。
- **D2** 变量名：存储 `tdx/tdy/tux/tuy/tms`，界面显示中文名。
- **D3** 取点另存通用变量：先不做。
- **D4** 按下/弹起单指（用起跑挑定的那个虚拟槽）；按住期间仅 等待/判断/弹起。
- **D5** 帮助 = 独立「说明」页。
- **D6** 无值变量引用 → 运行中报错中止（不静默 0）。
