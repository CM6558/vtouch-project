# OPS_PLAN_V6E —— 「框区域」步骤（运行时把某个区域的框画在屏幕上）

状态：**已拍板（2026-10-09 深夜；用户「按推荐」——§6 九项全按推荐）**。实施计划 = `OPS_IMPL_PLAN_V6E.md`。

## 1. 目标（用户口径对账）

- 新操作步骤类型 **22「框区域」**：执行到该步时，把**指定区域**的几何（矩形/圆）以醒目的高亮框画在屏幕上，持续一段时间后自动消失。
- 典型用途：① 平时把面板「显隐」切到「隐」的用户，用步骤**按需**把要看的区域框出来；② 运行时给用户一个明确的视觉提示（「看这里」）；③ 检查区域设置对不对。
- 已有基础（复用）：面板 `build_overlay`（`vtouch_ui.cpp:2248`）本来就在画全部区域（`p2c` 换算 `:2277-2285`、矩形/圆双形 `:2313-2314`、id/状态色系）；本批 = 加一条**核驱动的高亮通道** + 独立于「显隐」开关的高亮绘制。

### 能力对账表

| 想要的 | 现状 | 本批 |
|---|---|---|
| 把某区域「框出来」 | 面板「显隐」开关常显全部区域（绿/红按命中态）；无按需高亮 | 类型 22：核心发高亮信号 → 面板画琥珀高亮框（约 3 秒，自动淡出） |
| 指定哪个 | — | `ref` = 区域 id（编辑器胶囊选，含停用区域） |
| 时长 | — | `ms` 0..60000（0 = 默认 3000） |

## 2. 不可协商项对账

- **行格式不变**：step 行仍 10 字段；`ref`=区域 id、`ms`=时长、其余字段 0/空；新类型号 22（旧核心按条拒收、面板对未知类型行原样回写零改动）。
- **契约**：`VT_SHM_VERSION` 14 → 15（状态块加高亮通道：`hl_seq` + `hl_name[VT_NAME_BUF]` + `hl_ms`；两侧同二进制重建）。
- 高亮 = **非阻塞**（画完立即下一步）；同屏单高亮、新覆盖旧。
- 区域**不存在** → 运行时中止 `区域不存在`（同区域判断口径，防笔误）；区域**停用**（en=0）→ **照画**（要看的就是它）。
- 面板「显隐 = 隐」时**也画**（这就是按需显示的意义）；「显」时叠在常规描边上（高亮盖在上面）。

## 3. 设计

### 3.1 数据（类型 22）

- 字段：a1..a4 / j1 / j2 = 0；`ref` = 区域 id（必填，vt_id_ok 尺子；存在性不校验——运行时按 `区域不存在` 收场，同既有惯例）；`ms` = 时长 0..60000（0 = 默认 3000）；`expr` 空。
- 校验（`vt_ops.c` op_valid switch 加 case 22）：ref 必填且过 id 尺子（拒词沿用 `区域引用非法`）；ms 域；余字段 0/空。

### 3.2 运行时（`op_begin_step` 加 case 22）

- 在 `g.regions[]` 里按名查区域：找不到 → `vt_ops_abort("区域不存在")`。
- 找到 → 写高亮通道：`hl_name` 文本先写、`hl_ms` 再写、`hl_seq++`（release）；恒打日志 `op 框区域 <id>（<ms>ms）`；单拍 `PH_WAIT` 顺延。
- 不读几何、不算坐标（坐标换算全在面板侧，与 `build_overlay` 同链）。

### 3.3 显示（面板）

- `ui_glue.c`：加 `vtouch_hl_take(char *id, int cap, int *ms)`（对照 `vtouch_toast_take` 的 acquire + 读期重读模式）。
- `vtouch_ui.cpp`：新 `draw_region_hl(sw, sh)`（在 `draw_frame` 里 `draw_toast` 旁调用，**不经 `g_ov_show` 闸**）：
  - 新 seq → 记录显示窗口（单调钟 + ms，0→3000）→ `ui_glyph_scan(id)`（id 可能含中文）。
  - 每帧按名找区域（`vtouch_get_region` 循环匹配；找不到就不画）→ 复用 `:2277-2285` 的 `p2c` 换算（矩形取 min/max 归一、圆换算圆心）→ 绘制：
    **琥珀（ACCENT）描边 lw 5 + 12% 琥珀填充 + 呼吸脉冲（alpha 随单调钟 sin 脉动）+ 左上角 id 小标签（深底白字）**；末 300ms 淡出。
- 与「显隐」正交：隐=只看到高亮框；显=高亮框叠在常规描边上。

### 3.4 编辑器

- `Ops.java`：`T_HL = 22`、typeName「框区域」、解析闸 `>21`→`>22`、validate 镜像（ref 必填 id_ok / ms 域 / 余字段 0）、summary「框区域 · <id>（<秒> 秒）」。
- `StepEdit.java`：TYPE_NAMES/TYPE_IDS + build case（区域胶囊 = 全部 regionIds〔含停用〕+ 时长 Num + 说明行）；read 接线。
- `Forms.java`：typeSheet 加「框区域」条目（基础组，提示条目旁）。

## 5. 分期验收门（每门 = 可实测判据）

- **P0 校验层（导入日志）**：zte1 合法 put；zte2 ref 非法拒 `区域引用非法`；zte3 残留字段拒 `字段必须为 0`；zte4 ms 越界拒 `时长越界`。
