## 1. 目标与拍板记录

**目标**：给操作模型加"脚本级控制流"并可视化。要能表达（用户原话场景）：
1. 持续一段时间找图/找色，找到了就做某些步骤、做完继续找，如此重复；
2. 持续获取位置（fx/fy 每轮刷新）并持续做事；
3. 为后续同类需求留结构（嵌套 / 组合）。

**已拍板（2026-10-09，用户）**：
- 路线 = **核心原生结构化控制流**（否决"编辑器编译成跳转"与"折中"两条线）；
- 范围 = **全量**：循环（次数 / 时长 / 无限 / 到条件）+ 跳出循环 + 嵌套 + 条件块；
- 长时 = **挂机级**（几十分钟～小时级、可"无限直到手动停"）；
- 编辑器形态 = **C · 色带块风**（`~/vtouch-shots/loop-forms.png`）。

**非目标（留口，后加不返工）**：循环索引变量（"第几轮"）、循环体的复制/折叠动画等编辑器糖、多指同帧步骤、录制回填。

## 3. 设计

### 3.1 块模型（步骤类型 12..18）

| 类型 | 名称 | 作用 |
|---|---|---|
| 12 | 循环开始 | 块头；带模式与预算/条件；每次到达=一次"检查点" |
| 13 | 循环结束 | 块尾；到达=一次迭代结束→回跳或退出 |
| 14 | 条件块开始 | 块头；判定成立→执行体；不成立→跳到 15/16 |
| 15 | 否则 | 可选分支行；到达=跳到 16 |
| 16 | 条件块结束 | 块尾（无运行时动作，配对锚点） |
| 17 | 跳出循环 | 丢掉最内层循环（含体内任意层条件块嵌套）→ 继续 13 之后 |
| 18 | 继续循环 | 跳到最内层循环的 13 处（触发回跳检查） |

- 12↔13、14↔[15]↔16 必须配对且不交叉；嵌套深度 ≤ **8**；17/18 必须在循环内（校验见 §3.4）。
- 与现有 11 类共存；块内可以有任意普通步骤。

### 3.2 字段映射（复用 `step` 行 10 字段，按类型解释）

**12 循环开始**：

| 字段 | 语义 |
|---|---|
| a1 | 模式：0=次数 / 1=时长 / 2=无限 / 3=到条件 |
| a2 | 模式 0：次数 1..99999；模式 1：时长 ms 1000..86400000（≤24h）；模式 2：0；模式 3：判定类型 |
| a3 | 模式 3：区域判断=判定点 x（可变量编码）/ 找图=阈值 / 找色=模式 0/1 / 开关=0；其余模式 0 |
| a4 | 模式 3：区域判断=判定点 y（可变量）/ 找图=色校 0/1 / 其他 0；其余模式 0 |
| ms | 模式 3：找图/找色=持续查找 ms 0..60000；其余 0 |
| ref | 模式 3：区域判断/开关=区域名 / 找图=模板名 / 找色多点=点集名；其余空 |
| expr | 模式 3：找图/找色=区域限定（空=全屏）；其余空 |
| j1 | 模式 3：找色单点=(颜色<<8)\|容差；其余 0 |
| j2 | 恒 0 |

**13 / 17 / 18**：全字段 0 / 空。

**14 条件块开始**：

| 字段 | 语义 |
|---|---|
| a1 | 判定类型：0=区域判断 / 1=开关判断 / 2=找图 / 3=找色 |
| a2 | 区域判断=判定点 x / 找图=阈值 / 找色=模式 / 开关=0 |
| a3 | 区域判断=判定点 y / 找图=色校 / 其他=0 |
| a4 | 恒 0（保留） |
| ms | 找图/找色=持续查找 ms；其他 0 |
| ref | 区域判断/开关=区域名 / 找图=模板名 / 找色多点=点集名 |
| expr | 找图/找色=区域限定 |
| j1 | 找色单点=(颜色<<8)\|容差 |
| j2 | 恒 0 |

**15 / 16**：全字段 0 / 空。

> 实现口径：核心把"12 模式 3"与"14"的判定参数**归一到同一个内部规范结构**再求值（共用 `vis_exec_find` / 区域判定同一套底层），两组映射只在"读字段"一处不同。

**判定语义（四类，与既有判定步同义）**：区域判断=点∈区域（区域不存在→运行时按不成立）；开关判断=开关型区域"开着"（非开关型→运行时不成立）；找图/找色=同视觉步（命中写 fx/fy）。

### 3.3 运行时语义（执行器块栈）

- **起跑**：`vt_ops_run`（`src/vt_ops.c:1841`）除既有清零外，预计算**配对表** `R.pair[i]`（每个结构行→配对行的索引；O(64) 扫描，校验层已保证合法）并清空块栈。
- **块栈**：`R.blk[]`（深度 ≤8，仅循环层，元素 = {12 的索引、模式、剩余次数 / 起点时刻}）。条件块**不进栈**（14/15 的跳转靠配对表）。
- **12 执行**（首入或回跳到达）：模式 0：剩余次数--，>0 进体，否则弹栈→跳到配对 13 之后；模式 1：首入记起点，`now-起点 < 时长` 进体、否则退出；模式 2：进体；模式 3：求值判定（**成立→退出**；不成立→进体。即"直到条件成立"）。
- **13 执行**：查栈顶（必为本循环）→ 回跳其 12（触发下一轮检查）。**回跳不占旧跳转计数**。
- **17 执行**：弹栈至最近循环层 → 跳到该循环配对 13 之后；**18**：跳到该循环 13 处。
- **14 执行**：判定；成立→下一步；不成立→跳到 15+1（有否则）或 16 之后；**15 执行**：跳到 16 之后。
- **16**：无运行时动作（路过即顺延）。
- 每拍推进一步（与现有步骤节拍一致）；纯控制空转不加速（拍率即限速）。
- **中止/停止/门控/自动关/按住期规则**：全部沿用；结构行视为纯控制流（按住期允许，与跳转/计算同款）；中止路径清理块栈。
- **日志**（默认静默、`VTOUCH_OPS_TRACE=1` 全开）：TRACE 打结构行事件（`op 循环 <名> 第 N 轮 / 退出（原因）`、`op 条件块 <名> 成立|不成立`、`op 跳出/继续`）；循环回跳**不**打普通日志（防挂机日志洪水）；完成行沿用 `op 完成 <名> 用时=…ms`。

### 3.4 校验规则（核心 `op_valid` + app `Ops.validate` 同尺）

1. **配对与嵌套**：栈扫描；12↔13、14↔[15]↔16 配对不交叉；断配/交叉拒收（文案带步号）。
2. **深度**：嵌套 >8 拒收。
3. **17/18**：必须位于某循环（12..13）内，否则拒收；15 必须位于某 14..16 内。
4. **执行流不跨块**：跳转步目标、条件步跳转档目标（j1/j2）、以及"跳过下一步"的被跳过行，**不得是结构行（12..18）**、且跳转两端必须处于同一直接块层（或均在顶层）。旧数据（无结构行）天然满足。
5. **字段域**：按 §3.2 表逐类型校验（模式/次数/时长/判定类型/阈值/色校/范围打包/名字合法）。
6. 其余（步数 1..64、旧 11 类规则）照旧。

### 3.5 契约与尺寸（v12）

- `VT_SHM_VERSION` 11 → **12**（`src/vt_shm.h:30`）：布局变化 = `vt_op.steps[]` 扩容（版本号即混用保护）。
- `MAX_STEPS` 32 → **64**（`src/vt_internal.h:80`）。
- 尺寸核算：`vt_step` ≈148B → `vt_op` ≈10.4KB（name48 + gate48 + autooff + vars768 + steps 64×148 + padding）；`vt_shm_b` 含 payload → 超 8192，**断言改 12288（3 页）**（`src/vt_shm.h:111-113` 的 `_Static_assert` 与注释）。区 A/B 的 mmap 尺寸都取 `pg_up(sizeof(...))`（`src/vt_shm.c:79-83`）——自动跟结构体，无手工尺寸点。
- 面板镜像：`OPS_MAX_STEPS` 32 → 64（`src-ui/vtouch_ui.cpp:909`，独立定义；`load_ops` 的 `flat[OPS_MAX_STEPS*8]` 等数组自动跟）。
- 契约版本只由核心/面板互检（同体升级天然一致）；app 不读契约、不受影响。

### 3.6 落盘与兼容矩阵

结构行的落盘形态 = 标准 `step` 行（如 `step 12 1 1800000 0 0 0 - 0 0 -`）；**行格式与文件版本号都不变**。

| 组合 | 行为 |
|---|---|
| 旧 conf（无 12+）+ 任意版本 | 照常（零迁移） |
| 新 conf + 新核心（含面板）/ 新 app | 全功能 |
| 新 conf + 旧核心 | 含块的操作**整条拒收**（`op 被拒 <名>: 步类型未知`）；其余操作照常；文件无损 |
| 新 conf + 旧 app | 12+ 行按"未知类型 → 原样保留"（`Ops.java` 现有 raw 机制）读写不破坏；但旧 app 里**手动删除/移动**这些行会破坏结构 → 核心拒收（可见日志）。升级 app 即消除 |

部署：核心/面板 → `sh ~/vtouch-devbuild.sh` 构建 → `python3 scripts/pack_su.py` 重打包 → `su cp` 到 `/sdcard/vtouch.sh`（血泪：只换 `/data/local/tmp` 会被脚本内嵌旧载荷反向覆盖）；app → `bash ~/vtouch-editor/build.sh`。

### 3.7 编辑器（形态 C · 色带块风）

- **视觉**（用户选定 `~/vtouch-shots/loop-forms.png` C 案）：循环块 = 琥珀 6% 色底 + 左 3px 琥珀条；条件块 = 白 4% 底 + 左条（slate）；嵌套 = 内层再叠；块头行 = 类型 + 参数摘要（`循环 · 持续 30 分钟` / `如果 · 找图 boss`，琥珀粗体）；块尾行 = 灰小字（`循环结束` / `条件块结束`）。
- **编辑交互（初稿，P3 细化）**：块头点击 = 块属性编辑器（循环：模式 [次数/时长/无限/到条件] + 值；条件块：判定编辑，复用四类判定组件）；块头右侧 [＋] = 在块尾插入步骤；块尾行 [✕] = 删整块；步骤行保留 [✎][✕]；[↕ 移动] 升级为支持"移入块 / 移出块"；底部 [＋ 添加步骤] = 未选中加到操作末尾、选中块时加进该块。
- **StepFlow 总览**：块树缩进时间线（色条一致）。
- **app 侧校验**：与核心同尺的结构校验（§3.4），保存前跑，错误 toast 带步号。

### 3.8 日志

- 新增（TRACE 级，`VTOUCH_OPS_TRACE=1`）：`op 循环 <名> 第 N 轮` / `op 循环 <名> 退出（到点|次数用完|条件成立|跳出|停止）` / `op 条件块 <名> <成立|不成立>` / `op 跳出 <名> 第 A 步 → 循环后` / `op 继续 <名>`。
