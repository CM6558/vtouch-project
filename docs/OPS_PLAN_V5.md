# OPS_PLAN_V5 — 计算步骤（v5）

> 来源：用户 2026-10-03 拍板「加计算的步骤」（需求原文：「有时候需要根据按下弹起的坐标计算一些角度或者偏移来进行操作」）。
> 本文件是 v5 行为与文案的**唯一来源**；面板「说明」页的改动（§9）先改这里、再按同规则重提。
> 前序：v1–v3 = `docs/OPS_PLAN.md`；v4 = `docs/OPS_PLAN_V4.md`。v5 只加「计算」一类步骤，其余照旧。

## §1 语义总览

- 新步骤类型 **「计算」（第 9 类，type=9）**：`结果槽 = 表达式`。
- **结果槽 r1..r4**（4 个）：运行内有效、**起跑清零**、不落盘；表达式与后续步骤都可引用。
- **表达式**操作数 = 触发数据（tdx/tdy/tux/tuy/tms）、结果槽（r1..r4）、数字字面量；运算符 `+ - * /`、括号；函数 `atan2 sin cos abs min max sqrt`。
- 引用口径与变量完全一致：**起跑快照**、运行中不回填；无值 → 中止（`变量无值` 沿用；槽未写 = `结果无值` 新词）。
- 有了计算 + 槽，之前讨论过的「方向滑 / 锚点偏移」都能拼出来（例见 §5.5），不再单独做语义糖。

## §2 表达式语法（逐字规范）

```
expr    := term { ("+"|"-") term }
term    := unary { ("*"|"/") unary }
unary   := ["-"] primary
primary := number | var | slot | func "(" args ")" | "(" expr ")"
var     := "tdx" | "tdy" | "tux" | "tuy" | "tms"
slot    := "r1" | "r2" | "r3" | "r4"
func    := "atan2" | "sin" | "cos" | "abs" | "min" | "max" | "sqrt"
number  := 十进制整数 [ "." 十进制小数 ]
args    := expr { "," expr }
```

- 空白（空格、Tab、换行）忽略；大小写敏感（全小写）。
- 语义（逐条）：
  - `+ - * /`：double 运算；`/` 除零 → 错。
  - `atan2(y, x)`：两参数，返回**角度（度）**，范围 `(-180, 180]`；`(0,0)` 定义为 `0`。
  - `sin(x)` / `cos(x)`：参数为**度**，返回 double。
  - `abs(x)`：绝对值；`min(a,b)` / `max(a,b)`：两参数；`sqrt(x)`：`x < 0` → 错。
  - 一元负号 `-x` 允许（含 `--x`，不做特判）。
  - 参数个数不符（atan2/min/max 须 2 个、其余须 1 个）→ 错。
- 边界：长度 ≤ **63 字符**；括号嵌套 ≤ **8 层**；token 数 ≤ **128**；结果必须为**有限数**（inf/NaN → 错）。
- 求值输出：double（槽里存 double）。

## §3 存储与契约

- **ops.conf v4**：step 行 = **10 字段**
  `step <type> <a1> <a2> <a3> <a4> <ms> <ref> <j1> <j2> <expr>`
  - 计算步：`type=9`、`a1` = 槽号（1..4）、`expr` = 表达式（照写，空白无所谓）；其余照空规则（a2..a4=0、ms=0、ref=`-`、j1=j2=0）。
  - 非计算步：`expr` 写 `-`（哨兵，同 ref 口径）。
  - 读端兼容 v1(6 字段)/v2(7)/v3(9)：缺 `expr` → 视为 `-`；类型感知翻译照旧（type=9 只可能出现在 v4）。
- **契约：`VT_SHM_VERSION` 6 → 7**。step 结构加 `char expr[64]`（63 + NUL）；面板/核心的 step get/put API 加 expr 参。核心/面板版本不符照旧拒绝启动面板。
- 槽**不落盘**（纯运行态）；conf 里只有表达式文本。

## §4 校验（编辑期；核心 op_valid 为唯一权威，面板调同源函数镜像）

- 计算步：`a1 ∈ 1..4`；`expr` 非空、≤63、且**可解析**（标识符白名单：未知名字 → 错）；防御：a2..a4/ms/j1/j2 必须 0、ref 必须空。
- 其他步：`expr` 必须为空（文件层写 `-` 哨兵；结构/共享内存层只收空串）。
- **负数编码扩展**：所有「允许变量」的字段（点按 a1,a2；滑动 a1..a4；按下 a1,a2；区域判断 a1,a2；时长字段）现在接受 **-1..-9**：-1..-5 = 触发变量（照旧）、-6..-9 = r1..r4。条件步档位/j1/j2/跳转目标照旧只收字面值。
- 拒绝词沿用 `op 被拒 <名>: <原因>`（新原因：`表达式错`）。
- 面板侧：表达式子层 [确定] 时调用**同源** `vt_expr_check`（面板 real 构建链核心源码，不重复实现解析器）；不过 → 就地拒收（子层不关）。

## §5 执行器（核心主线程）

1. **起跑**：槽清零（值 + 未写标记）；触发快照照旧。
2. **计算步**：现解析现求值（≤63 字符，µs 级；一条操作一次只跑一条，无热路径顾虑）→ 写槽（覆盖）→ 步级日志。
   - 求值错（除零/域错/非有限/解析失败——编辑期已拦，这里是防御）→ 中止 `表达式错`。
   - 引用未写的槽 → 中止 `结果无值`；引用无值的触发变量 → 中止 `变量无值`（沿用）。
   - **按住期间允许「计算」**（纯计算不碰手指；`槽占用` 的允许集 = 等待/区域判断/开关判断/弹起/跳转 **+ 计算**）。
3. **槽引用（字段里的 -6..-9）**：取槽值 → **四舍五入取整** → **夹取**到字段合法域（坐标 `0..逻辑尺寸-1`；时长按类型档位上限）→ 继续执行（不因越界中止；夹取是静默语义）。
4. 槽贯穿整次运行（跳转/循环照常；跳转上限 200 不变；计算不计跳转数）。
5. **示例（验证「方向滑」可拼）**——用户从 A 滑到 B，虚拟从按下点沿同方向滑 300px：
   - `计算 r1 = tdx + cos(atan2(tuy-tdy, tux-tdx)) * 300`
   - `计算 r2 = tdy + sin(atan2(tuy-tdy, tux-tdx)) * 300`
   - `滑动 起点=(tdx,tdy) 终点=(r1,r2)`
   - 「反向」= 角度 +180；「偏移点按」= `计算 r1 = tux + 50` + `点按 (r1, tuy-30)`。

## §7 日志（逐字）

- 步级：`op 步 k/n 计算 r1 = 30`（值 = 取整显示）。
- TRACE（`VTOUCH_OPS_TRACE=1`）：`op 计算 r1 = <表达式> = 30`（回显原文）。
- 中止：`表达式错` / `结果无值` 两个新原因词（同步进 §9 第 12 条速查）。
- 编辑：`op edit 计算 第 N 步 r1 = <表达式>`（确定时）；拒收 `op edit 计算拒收 第 N 步：<原因>`。

## §9 说明页（16 条；1–15 承 v4 §12，其中第 12 条更新，新第 16 条逐字如下）

- 第 12 条（更新，+2 词）：
  > 12. 中止原因速查：变量无值 / 结果无值 / 表达式错 / 槽占用 / 未按下 / 区域不存在 / 非开关型 / 条件不成立 / 条件中止 / 跳转超限。
- 新第 16 条（逐字）：
  > 16. 计算：算一个数存进结果槽（r1–r4）——用触发数据（tdx/tdy=按下坐标、tux/tuy=弹起坐标、tms=按压时长毫秒）、数字和结果槽做加减乘除，也能用 atan2、sin、cos、abs、min、max、sqrt（三角函数按度）。算好的槽可以当坐标、时长用在后面的步骤里。

## §10 拍板点（已按推荐定；要改哪条直接说）

1. 槽数 = 4（r1..r4）。
2. 函数集 = 7 个、三角函数按**度**、atan2 返回 `(-180,180]`。
3. 编辑 = **追加式**（末尾退格/清空，无光标移动）——v1 简化，够用再看。
4. 错误口径：除零/域错/非有限 → 中止 `表达式错`；槽值作坐标/时长越界 → **夹取**（不中止）。
5. 加步区改 **3×3**（新增「＋计算」；顺带每钮更宽、窄屏更稳）。

## §11 明确不做（v5 边界）

- 无字符串/比较/逻辑表达式、无自定义函数、无循环（用跳转步）。
- 槽不落盘、不跨操作共享。
- 表达式编辑无光标移动（追加式）。
- 不做「方向滑/方向判断/锚点偏移」独立语义糖（计算 + 槽已覆盖，§5.5 为例）。
