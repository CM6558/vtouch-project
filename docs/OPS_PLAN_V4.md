# 方案（Profiles）设计 v4（区域+操作打包：切换 / 新建 / 另存为 / 重命名 / 删除）

> 状态：设计稿定稿（2026-10-02 用户「按推荐走」= D1-D6 全收）。
> 前置：v1–v3（操作编辑器 / 触发侧 / v3 分支·跳转·预览）。实施排 v3 交付之后。
> 口径承接：落盘只在 `/data/local/vtouch-runtime/`；**核心与契约零改动**（用现有编辑邮箱清空+重放）；WS 协议零改动；面板日志照既有 ALOGI 口径。

## §0 需求 → 特性映射

| 用户原话（2026-10-02） | 特性 | 落点 |
|---|---|---|
| 「把当前的区域，还有操作，都保存成一个方案」 | 方案 = 命名打包（regions.conf + ops.conf）；「从当前另存为」 | §1 / §5 |
| 「切换方案」 | 切换执行（清空 + 重放 + current） | §4 |
| 「新增，删除，重命名」 | CRUD + 命名规则 | §5 |

## §1 概念与存储布局（D1）

- **方案** = 命名的一套「区域表 + 操作表」，以两份**现成文件原样**承载（格式零改动）：
```
/data/local/vtouch-runtime/
  regions.conf          # live（当前工作副本；REGION_CONF_VER 格式不变）
  ops.conf              # live（OPS_CONF_VER 格式不变）
  current               # 一行方案名（无换行）
  schemes/<名>/
    regions.conf        # 与 live 同款（含 bind / kind 增量行）
    ops.conf            # 与 live 同款（含 gate / autooff）
```
- **不变量**：`live == schemes/<current> 内容`（启动强制同步 §2 + 存盘镜像 §3 + 切换直写 §4 共同保证）。
- **命名规则（D3）**：`[A-Za-z0-9_-]`、1..15、裸 `-` 除外（与区域/操作 id 同一把尺子 `vt_id_ok`；目录名 = 方案名）。
- 实现归**面板**（文件与 UI 都归面板）；核心不感知方案。

## §2 启动接管与迁移（D5）

面板启动段（`load_regions(); load_ops();` 调用点之前）插入「方案接管」：

1. 读 `current`；缺失/为空 → 走迁移。
2. 校验 `schemes/<cur>/` 存在且两文件齐；缺失 → 走迁移兜底。
3. **强制同步**：把 `schemes/<cur>/` 两文件复制到 live 两路径（启动点保证不变量成立）。
4. 之后照旧 `load_regions(); load_ops();`（读 live 推核心，既有逻辑一行不改）。

**迁移（首启与兜底同一套）**：
- live 任一文件存在 → 建 `schemes/默认/`，把 live 两份复制进去（缺失那份写空合法文件）+ `current` = 默认；
- 全新（live 也没有）→ 建 `schemes/默认/`（空表）+ current = 默认；
- 名字冲突（默认已存在）→ 自增 `默认2 / 默认3 …`；
- 日志 `方案 兜底迁移 → <名>（区域 N / 操作 M）`。
- 空表合法文件 = 各表当前版本行（照 `REGION_CONF_VER` / `OPS_CONF_VER` 现定义）各一行。

## §3 保存管线：镜像钩子（D1）

- 既有编辑保存（`save_regions` / `save_ops` 落盘成功后）**追加**：把刚写出的 live 文件复制到 `schemes/<current>/` 同名文件。
- 失败：`方案 镜像失败 <名>: <errno>`（ALOGE），不阻塞、不回滚（下次存盘自然补齐；切换另有 flush 兜底 §4-③）。
- 实现：小工具 `scheme_mirror()`；两处 save 成功后各调一次。

## §4 切换执行（D2）

`scheme_switch(new)`（面板；编号即事务边界与顺序）：

1. **预检**：只读解析 `schemes/<new>/` 两文件（dry-run 一遍现有解析器）；坏行 → 拒切（就地提示），保持原状。`new == current` → 直接返回。
2. **静默边界**：操作在跑 → `vtouch_op_stop()`；关取点态 / 编辑覆盖层及子层（UI 态复位）。
3. **flush 旧**：live 两文件直写回 `schemes/<old>/`（兜底镜像；失败仅告警）。
4. **写 live**：`schemes/<new>/` 两文件 → live 两路径。
5. **核心替换**：`vtouch_region_clear()` → 逐条重放区域（含 bind / kind）→ `vtouch_op_clear()` → 逐条重放操作。**先区域后操作**（引用关系）。
   - 复用现有 load 逻辑（清空后「只补缺 / 重复跳过」均不触发 ⇒ 全量补入）；load 函数需**可重入**（切换期再跑一遍，行为不变）。
   - 单条被核心拒收 → 照既有「坏记录单条跳过 + 警告」口径（可见失败，不算切换失败）。
6. **写 `current`** = new（.tmp + rename）。
7. **UI 刷新** + 日志 `方案 切换 <旧> → <新>（区域 N / 操作 M）`。

**失败面**：1 失败 → 拒切、原状；2–4 失败 → 核心未被触及、原状（3 的失败仅告警）；5 的拒收 = 逐条可见；6 失败 → 下次启动兜底迁移。

## §5 CRUD（D4 / D3）

- **新建（空）**：名字校验（合法 + 不撞现有目录）→ 建目录 + 两空合法文件；**不自动切换**；日志 `方案 新建 <名>`。
- **从当前另存为**：名字校验 → 把 live 两文件复制进 `schemes/<名>/` → `current` 改为新名（内容相同，无需动核心）；日志 `方案 另存为 <名>`。
- **重命名**：校验 → 目录改名；若 current == 旧名 → `current` 写新名；日志 `方案 改名 <旧> → <新>`。
- **删除**：**不允许删除当前**（拒绝 + 提示）；确认弹层后删目录；日志 `方案 删除 <名>`。

## §6 面板「方案」页（D4）

- 左侧菜单新页「方案」（与「操作」邻近注册）。
- 布局（承现有列表页口径：可滚 + `SCR_LIST` 拖滚）：
  - 当前方案行（高亮）。
  - 方案列表：每行方案名 + [切换]（当前行按钮禁用）。
  - 底部四键：[新建] [从当前另存为] [重命名] [删除]。
- 子层：名字输入（复用 `draw_char_kb`，ASCII）；删除确认（新小确认层：[取消][删除]，文案「删除方案 <名>？不可恢复」）。
- 切换结果就地提示（复用页面提示槽位口径）。

## §7 核心 / 契约影响

- **零改动**：只用现有 `VT_EDIT_CLEAR`（区域清空）/ `VT_EDIT_OP_CLEAR` / 区域 ADD / `VT_EDIT_OP_PUT` / `VT_EDIT_OP_STOP`。
- `VT_SHM_VERSION` 不动（仍 6）；**默认 / UI 核心 md5 不变**；real 面板随面板改动重算（记录新值×2）。
- WS 协议零改动。

## §8 日志增量（面板 ALOGI 口径，逐字）

- `方案 兜底迁移 → <名>（区域 N / 操作 M）`

## §9 测试清单

- **宿主仿真**（面板文件逻辑；build/ 下不入库）：迁移三情形（有 live / 全新 / 默认冲突）；切换往返幂等（A→B→A）；预检拒切（坏行）；CRUD（非法名 / 重名 / 删当前拒绝 / 改名同步 current）。
- **真机**：首启迁移（设备现有数据无感收进「默认」）；建两方案来回切（区域 / 操作 / 绑定 / 开关型全量正确）；重启保持 current；编辑即时镜像。

## §12 说明页增量（v4 起面板文案唯一来源 = 本节；全量 15 条）

（1–13 承 `OPS_PLAN_V3.md` §9，逐字；14–15 为 v4 新增。）

1. 触发：给区域绑一条操作；手指碰到这个区域就会跑那条操作。
2. 时机·按下：手指碰到区域的那一刻就跑。
3. 时机·完整按压：手指碰到、抬起后跑（按一下、抬起来，才算数）。
4. 开关型：把区域当开关——每完整按压一次，「开/关」翻转一次（绿色 = 开）。
5. 门控：操作的门禁——绑一个开关型区域，它开着，操作才允许跑。
6. 跑完自动关：操作正常跑完后，自动把门控开关翻回「关」。
7. 取点：点 [取点]，然后去屏幕上点一下——那个坐标对（x 和 y）一次填进正在编辑的位置，并在屏上标一下。
8. 变量（触发数据）：这次触发的那根手指——触发按下x / 触发按下y（按下位置）、触发弹起x / 触发弹起y（抬起位置）、触发时长（按下到抬起的毫秒数）。「完整按压」触发时全都有； 「按下」触发只有按下位置；面板手动运行没有。
9. 按下 / 弹起：两条分开的步骤——按下 = 按住不放；弹起 = 松开。中间可以夹「等待」「判断」。
10. 区域判断：检查一个点在不在某个区域内；成立 / 不成立两侧各选接下来做什么：继续下一步、跳过下一步、跳到第 N 步、中止（可以只配一侧，另一侧走默认）。
11. 开关判断：检查某个开关型区域现在是不是「开」；成立 / 不成立两侧的选项同「区域判断」。
12. 中止原因速查：变量无值 / 槽占用 / 未按下 / 区域不存在 / 非开关型 / 条件不成立 / 条件中止 / 跳转超限。
13. 跳转：直接跳到指定步骤继续——往前跳 = 跳过中间步骤；往后跳 = 循环（比如跳回第 1 步重来）。目标也可以选「结束」直接完成操作；单次运行跳转超过 200 次会自动中止（防死循环）。
14. 方案：把当前的区域和操作整体存成一个命名方案；切换方案 = 换成那一套（编辑会自动存回当前方案）。
15. 方案管理：「方案」页可以新建（空白）、从当前另存为、重命名、删除；当前方案不能删（先切到别的方案再删）。
