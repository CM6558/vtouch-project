# OPS_PLAN_V6F —— 「框矩形」步骤（指定任意矩形坐标，运行时框出来）

状态：**已拍板（2026-10-09 深夜；用户「按推荐」——§3 八项全按推荐）**。实施计划 = `OPS_IMPL_PLAN_V6F.md`。（原话：「不是框区域，是想指定屏幕上任意的一个矩形范围框选出来，用途可能是想把找图找色的位置标出来」）

## 1. 修正纪要

- **V6E「22 框区域」理解偏差**：做成了「按区域名高亮已登记的区域」。用户要的是 **任意矩形范围**（给坐标），典型用途 = **把找图/找色的命中位置标出来**（找图命中会写 fx/fy，坐标字段又支持变量编码 → 天然可联动）。
- 本批新增 **类型 23「框矩形」**；22「框区域」暂时保留（已有且不冲突，也是「检查区域位置」的顺手工具）——是否撤掉见拍板②。

## 2. 设计（复用 V6E 全套基建）

### 2.1 数据（类型 23）

- `a1..a4` = **x1, y1, x2, y2**（四角坐标）：字面 0..逻辑尺寸-1，或负数编码引用（-25..-1：-1..-5 触发变量 / -6/-7 = fx/fy / -10..-25 自定义）——**与点按/区域判断同口径、同一把尺子**。
- `ms` = 时长 0..60000（0 = 默认 3000）；`ref`/`expr` 空；`j1`/`j2` = 0。
- 四角顺序**自动归一**（x1>x2 或 y1>y2 自动交换，画出来的框永远正）。

### 2.2 运行时

- `op_resolve` 逐个解析四坐标（**缺值中止**同点按：`变量无值` / `结果无值`）→ 归一 → 写高亮通道 → 恒打日志 `op 框矩形 x1,y1–x2,y2（ms）` → 单拍不阻塞。

### 2.3 通道与显示（契约 v15 → v16）

- hl 通道泛化：加 `hl_kind`（0 = 区域名〔22 用〕/ 1 = 矩形〔23 用〕）+ `hl_x1/hl_y1/hl_x2/hl_y2`；原 `hl_name/hl_ms` 不动。
- 面板 `draw_region_hl` 两模式分支：kind 1 直接用四坐标（**同一套 `p2c` 换算**：矩形两角取 min/max）→ 绘制样式沿用 V6E（琥珀描边 + 12% 填充 + 呼吸脉动 + 末 300ms 淡出；**不经「显隐」闸**）。矩形模式**无标签**（纯框）。

### 2.4 编辑器

- 类型 23：四行坐标输入（x1/y1/x2/y2），**带变量插入按钮**（复用点按坐标控件）；时长同 22；typeSheet 基础组加条目。
- 摘要：`框矩形 · (x1,y1)–(x2,y2)（3 秒）`（含槽名显示）。

### 2.5 典型用法（验收用）

```
找图 tpl1 …            → 命中写 fx/fy
计算 e9 = fx-60  计算 e10 = fy-60  计算 e11 = fx+60  计算 e12 = fy+60
框矩形 e9,e10,e11,e12 3000        → 命中处框一个 120×120 的框
```
