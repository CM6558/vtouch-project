## 3. 设计

### 3.1 多条件并或（类型 19「子条件」）

**结构**：块头（14 条件块 或 12 模式3 循环）后紧跟 **0..N-1 条 19 行**（连续、体之前）；头行本身 = 条件 1。适用范围 = 条件块 + 循环·到条件（内联条件步 6/7/10/11 不改，留口）。

**字段映射（19；复用 step 行 10 字段）**：

| 字段 | 语义 |
|---|---|
| a1 | 连接：0 = 且 / 1 = 或（与前一子条件之间） |
| a2 | 判定类型：0 区域判断 / 1 开关判断 / 2 找图 / 3 找色 |
| a3 | 区域判断=判定点 x / 找图=阈值 / 找色=模式 / 开关=0 |
| a4 | 区域判断=判定点 y / 找图=色校 / 其他=0 |
| ms | 找图/找色=持续查找 ms 0..60000；其余 0 |
| ref | 区域名 / 模板名 / 点集名 |
| expr | 找图/找色=区域限定（空=全屏）；其余空 |
| j1 | 找色单点=(颜色<<8)\|容差；其余 0 |
| j2 | **取反** 0/1（拍板②） |

**头条件取反**（字段复用，原恒 0 位）：14 → `a4`；12 模式3 → `j2`。

**上限**：每头合计 ≤ **4 个子条件**（1 头 + 3 条 19）【拍板①】。

**求值（精确等价代码短路语义，且 > 或）**：

```
result = false; group = eval(c1)
for i = 2..n:
    if J(i) == 且:
        if group: group = eval(ci)        # 组内继续
        # group=false 时跳过 eval(ci)（且链短路，不求值）
    else:                                  # 或
        result = result || group
        if result: stop                    # 已真 → 整式真，其后全部不求值
        group = eval(ci)
final = result || group
```

- `a 或 b 且 c` = `a || (b && c)`；`a 且 b 或 c` = `(a && b) || c` —— 与 C/Java 一致。
- **被短路跳过的子条件不发生求值**（不写 fx/fy、不触发判定异常）；**被求值的**子条件异常 = 中止（口径与条件步一致，找图/找色命中照写 fx/fy、区域/开关同款锁纪律）。
- 取反：每条子条件求值后取非（`!hit`），短路按**取反后的值**计算（例：`非 A 且 B`，A 命中 → 非A=假 → B 不求值——与代码 `!a && b` 逐字等价）。

**校验（核心 `op_valid` + app 镜像）**：
1. 19 必须**紧跟前行** =「14 / 12 模式3 / 19」之一（链连续、体之前）；链根必须是 14 或 12 模式3，否则拒 `子条件位置错误`；12 非模式3 后跟 19 同拒。
2. 链长（头 + 19 条数）≤ 4，超限拒 `子条件超限`。
3. 19 字段域 = 判定表（共用 `op_ctrl_cond_bad` 扩展 join/取反两参）+ a1∈{0,1} + j2∈{0,1}。
4. 头/子条件取反字段域 0/1：14.a4、12(mode3).j2、19.j2。
5. **结构行集合 12..18 → 12..19**：跳转目标、条件步跳转档目标、「跳过下一步」被跳过行，不得落在 12..19 上且不得跨块（两处范围常量同改：`vt_ops.c:274/635/645`、`Ops.java:405/552/562` 同类）。
6. 其余规则（配对/深度/17-18 归属/字段域）不变。

**执行器**：
- `op_pair_build`（`:1191`）不变（19 不参与配对；防跨块靠校验层）；R 增 `cl_end[MAX_STEPS]`（每头→链尾下标；顺扫一遍即可）或等价运行时助手。
- 12(mode3)（`:2046`）与 14（`:2098`）的判定改调新 `op_ctrl_eval_list(head_idx)`（扫链 + 上述求值）。
- `op_begin_step` 新增 `case OP_STEP_CLAUSE`：纯前进（`PH_WAIT`；头行求值成立后自然走过链，tick 级开销 ≈ 微秒，无需显式跳转）。
- 日志：默认级零新增；TRACE 增每条子条件求值行 `op 子条件 <名> 第 K 条 <且|或> <成立|不成立>`（挂机防洪水，仅 TRACE）。

**编辑器（拍板⑥：编号子行呈现）**：
- 类型弹层**不含** 19（头绑定，不进独立添加入口）。
- 块编辑器（StepEdit）：条件区升级为**条件列表**——条件 1（现编辑器）+ 子条件行（每条 = [且|或] Seg + 判定编辑器（复用四类）+ 取反 SwitchRow + [✕]）+ [＋ 加子条件]（≤上限，超出置灰）。
- 保存路径：单步替换 → **组替换** `Ops.setClauseGroup(steps, headIdx, header, clauses)`：校验后一次性 splice（头 + 链）；越限/失败回退并 toast。
- 卡片列表：19 行渲染为**块头下的编号子行**（`N. 且 · 开关判断 s1`；暗色、缩进=块头层、在色带壳内）；点子句行 = 打开块编辑器（聚焦该子句）。头行摘要保持条件 1。
- 总览：同款子行（缩进线内、`且 · …` 前缀）。
- `[↕ 移动]`：19 行与**带子条件的块头**禁用（DIM + toast「子条件随块头管理，先删除子条件」）【拍板⑥副】。
- 删整块（`OpsPage:691`）自动带走链；`pairTail/ifTrueTail/blockHeadOf/insertStep` 不受链影响（19 不计深）。

### 3.2 终止（类型 20）

**字段**：a1 = 模式：**0 = 完成收工 / 1 = 中止退出**；其余 0/空。

| 模式 | 行为 | 日志 |
|---|---|---|
| 0 完成收工 | 走 `op_finish`：收尾释放 + `op 完成 <名> 用时=…` + done 环行 + **autooff 照走**（门控开关翻回关——挂机脚本「找到目标即收工」的正解） | 默认级同现状 |
| 1 中止退出 | 走 `vt_ops_abort("终止")`：收尾释放 + `op 中止 原因=终止`；**不翻 autooff** | 新中止词 `终止` |

- 位置：任意步位（顶层/块内/嵌套/按住期均可）；**可被跳转指向**（普通执行步，非结构行）。
- TRACE：`op 终止 <名> 第 N 步 → 完成|中止`。
- 编辑器：类型弹层「流程控制」组新增「**终止**｜立即结束整个操作（完成收工 / 中止退出）」；StepEdit = 模式 Seg + 一句话说明；摘要 `终止 · 完成收工` / `终止 · 中止退出`。

### 3.3 跳出 / 继续 N 层（17/18 扩展）【拍板④】

- `a1` = 层数 **1..8**；**0 = 兼容旧数据视作 1**；校验 1..8 且 ≤ 该步处循环嵌套深度。
- 执行：弹出 N-1 层后按现语义（17 → 目标循环 13 之后；18 → 目标循环 13）。栈不足防御照旧。
- 编辑器：跳出/继续编辑页加「层数」步进（默认 1）；摘要 `跳出循环（2 层）`（=1 层不标）。
- 兼容：新核心读旧数据 a1=0 → 1 层 ✓；旧核心读 a1>0 → 拒该条（预期）。
