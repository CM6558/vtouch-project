## §1 源文件与总则

- [定] 一个 `.vts` 文件 = 一个操作；文件名 = 操作名（v11 名字尺子：可见 UTF-8 字符 1..15、字节 ≤47）。
- [定] 编码 UTF-8；行尾 `\n`（兼容读 `\r\n`）。
- [定] 注释：`#` 到行尾。
- [定 r8] 编辑器模式侧线：头注释 `#模式 块` / `#模式 脚本`（编辑器保存时写入 = 双视图单模锁定的持久形态；编译器与运行时
  视作普通注释忽略；缺省（迁移产物等）按「可投影 → 块，否则脚本」推导；保存时归一为首行唯一一条）。
- [定] 语句分隔：换行或 `;`；块 = `{ … }`（可同行可多行；括号必须配对）。
- [定] 门控 / 自动关等**操作级元数据不进脚本**（在 `ops.conf v8` 元数据里，编辑器管理）。
- [定] 源文件 ≤64KB（超限 `文件过大`）。**操作名（= 文件名）仍按 v11 尺子（盘上兼容，受限）；脚本内名字不受 v11 限制**（见 §2）。
- [定] 关键字全中文；运算符/标点 ASCII。标识符不可与保留字/内建名重名（`保留字` 拒）。

## §2 词法

- [定] 数字：十进制整数/小数（`1`、`1.5`；`.5`、`1.` 非法）＋ 十六进制 `0x` + 1..8 位（`0xC81E1E`，查色用）。
- [定] 字符串：`"…"`；UTF-8 任意字符；转义 `\"` `\\` `\n` `\t`（其余 `\x` → `字符串转义非法`）。
- [定] 字符串插值：`{名}`、`{表名[下标]}`（下标 = 数字/变量名），`{{`/`}}` 为字面花括号；
  编译期展开为拼接（与 V6D 提示模板是同一机制的超集，旧模板是子集 ✓）。
- [定] 标识符（变量/函数/表）：可见 UTF-8 字符 1..63、首字符非数字；字符集 = 字母/数字/`_`/非 ASCII
  （不含 `-`；v11 尺子允许内嵌 `-` 的旧名，迁移时报告改名——T5）。
- [定] 关键字/标识符按**最长匹配**扫描：关键字与后续内容之间须用空格/标点分隔（`循环3` 是一个标识符，不是 `循环 3`）。
- [定] 保留字表（44 词，不可作名字）：`点按 滑动 等待 按下 弹起 如果 否则 循环 当 直到 跳出 继续 终止 返回 函数 表 无限
  跳转 结束 提示 框区域 框矩形 找图 找色 找色点 在区域 开关开 轮 真 假`＋内建函数名
  `len str num rand floor ceil round abs min max sqrt sin cos atan2`。
- [定] **语境词**（非保留，可作普通名字）：命名参数键 `时长 停1 停2 阈值 持续 色校 区域 模式 容差 次数`
  （仅出现在 `键=值` 的键位时才是键）；循环计数词 `从 到`（仅 `循环 i 从 a 到 b` 中成对出现时有语法义）；
  `中止` 仅在 `终止 中止` 中成词。`按住` 自 r3 起为普通词（点按 ms 改为第 3 位置参数）。
  例：`时长 = 300` 是给变量"时长"赋值；`滑动 1 2 3 4 时长=300` 里 `时长=` 才是参数键。

## §3 语句表（与现行步骤/执行器的语义映射）

| 语句 | 语法 | 语义（↔ 现状） |
|---|---|---|
| 点按 | `点按 x y [ms]`（按住时长；默认 50） | ↔1 |
| 滑动 | `滑动 x1 y1 x2 y2 [时长=ms 停1=ms 停2=ms]` | ↔2 [对齐]默认时长 |
| 等待 | `等待 ms` | ↔3 |
| 按下 / 弹起 | `按下 x y` / `弹起` | ↔4/5 |
| 赋值 | `名 = 表达式`；`表名[下标] = 表达式` | ↔9（表写入 = 现"表"扩展） |
| 条件 | `如果 表达式 { … } [否则 { … }]` | ↔14/15/16（条件 = 表达式，含视觉函数） |
| 循环·次数 | `循环 3 { … }` 或 `循环 次数=3 { … }` | ↔12 模式0 |
| 循环·时长 | `循环 时长=5000 { … }` | ↔12 模式1 |
| 循环·无限 | `循环 无限 { … }` | ↔12 模式2（挂机；[停止] 为出口） |
| 循环·到条件 | `当 表达式 { … }`（while）/ `直到 表达式 { … }`（until） | ↔12 模式3（首判；取反） |
| 循环·计数 | `循环 i 从 1 到 10 { … }` | for 糖（i = 帧局部计数变量，含端点；步长 1；帧内全程可见——循环结束后仍可读） |
| 跳出/继续 | `跳出 [层数]` / `继续 [层数]` | ↔17/18（层数 1..8，默认 1；超过嵌套深度 → `跳出在循环外`） |
| 终止 | `终止`（完成收工）/ `终止 中止` | ↔20 |
| 提示 | `提示 表达式 [时长=ms]` | ↔21（ms 默认 2000） |
| 框区域 | `框区域 "区域id" [时长=ms]` | ↔22（默认 3000） |
| 框矩形 | `框矩形 x1 y1 x2 y2 [时长=ms]` | ↔23（默认 3000） |
| 函数定义 | `函数 名(参数,…) { … }` | 新（仅顶层；参数 ≤32；调用深度 ≤32；递归允许） |
| 返回 | `返回 [表达式]`（仅函数内） | 新（无值 = 结果未写） |
| 调用 | `名(实参,…)`（语句）；`结果 = 名(实参,…)` / 表达式位置 | 新（**组合式调用支持**：`x = f(g(tdx))`） |
| 表定义 | `表 名[64]`（仅顶层；长度 1..4096，省略 = 64；张数不限） | 新（起跑清零） |
| 兼容·跳转 | `跳转 第N行` / `跳转 结束` | ↔8（迁移产出可用；占 200 跳守卫；编译期不得进/跨块） |

**参数键支持集** [定]（r3）：点按 `∅`（ms = 第 3 位置参）、滑动 `时长 停1 停2`、等待 `∅`、提示 `时长`、框区域 `时长`、框矩形 `时长`、
循环 `次数 | 时长`（至多一个模式键）、找图 `区域 阈值 色校 持续`、找色 `区域`、找色点 `容差 区域`、按下/弹起/开关开/在区域 `∅`；
不在支持集 / 重复键 → `参数不匹配`。

**默认值** [对齐→已坐实 r5]（与现编辑器 `newStep`（`OpsPage.java:553`）/ `StepEdit` 核实，2026-10-10）：
点按 ms 50；提示 2000；框区域 3000；框矩形 3000；滑动 时长 300（编辑器无缺省=必填，脚本省略取 300；停1/停2 缺省 0=不停）；
找图 阈值 8 / 色校 0 / 持续 0（单帧）；找色点 容差 8；按下/弹起/等待 参数必写无缺省；循环头必写（编辑器默认 3 仅为 UI 值）。

## §4 表达式（= V7 表达式 v2 全量 + 视觉函数）

- 运算符：`+ - * / %`、`> < >= <= == !=`、`&& || !`、括号、一元负；比较/逻辑结果 = 1/0；真假 = 非零。
- 字符串：`+` 兼任拼接（任一侧为串；数值自动转，小数 ≤6 位）；`len/str/num`。
- 比较：`==`/`!=` 允许字符串（任一静态侧为串 → 串相等比较）；`< > <= >=` 仅数值（静态串 → `类型错`）。
- 函数库：`rand(a,b)`（含端点整数）、`floor/ceil/round`、`abs/min/max/sqrt/sin/cos/atan2`（度）。
- 视觉/判定函数（**求值有副作用，与现判定族一致**；模板/点集/区域/开关名 = 字符串字面量，编译期入常量池，否则 `参数不匹配`）：
  - `找图("模板"[, 区域="r9", 阈值=8, 色校=0|1, 持续=ms]) → 1/0`（命中写 fx/fy；持续 = 现"持续查找"）
  - `找色("点集"[, 区域=…]) → 1/0`（多点）；`找色点(0xC81E1E[, 容差=8, 区域=…]) → 1/0`（单点）
  - `在区域("r9", x, y) → 1/0`；`开关开("s1") → 1/0`（非开关型 → 运行期 `非开关型` 中止）
- 内建只读：`轮` = 当前最内层循环序号（0 起；循环外引用 → 编译期拒 `循环外引用 轮`）；`真`/`假` = 1/0。
- 短路：`&&`/`||` 短路侧不求值（含视觉函数——被短路不查、不写 fx/fy；与现行子条件"短路不求值"口径一致）。
- 表读取：`名[下标]`；越界 → 运行期 `下标越界`（带行号）。

## §5 值 / 类型 / 作用域

- 值域：数值（double）| 字符串。变量/表项/参数/返回值均为二者之一。
- 变量：首次赋值即定义；数量不限（编译期分配槽，受程序体积自然约束）；**起跑：变量为空（先读 → 运行期 `变量无值`）、表项为 0**；不落盘（持久化留口）。
- 作用域：函数参数 = 帧局部（不污染调用方）；变量/表 = 全局共享（函数内读写同一份）。
- 预定义变量（恒可读写，7 个）[定 r4]：`tdx tdy`（触发按下点）、`tux tuy`（触发抬起点）、`tms`（触发时刻 ms）、
  `fx fy`（视觉命中坐标）；写 = 直接改槽（同现"计算步写 fx/fy"）；未写先读 → 运行期中止（词族见 §6，T3 与核心对齐）。
- 名字解析顺序（编译期定死）：局部（参数/计数变量）→ 全局变量 → 表名 → 内建/保留 → 未定义报错。
- 类型可静态判的（字符串入条件、字符串做算术）编译期拒；不可判的运行期中止 `类型错`（带行号）。

## §6 错误词表

**编译期**（编辑器显示 `第 N 行: <词>`）：
`语法错误`（词法/结构近因另附）、`块未闭合`、`否则不匹配`、`括号不匹配`、`表达式为空`、`嵌套过深`(>32)、
`未定义: <名>`、`重名: <名>`、`保留字: <名>`、`参数不匹配`（实参≠形参；参数 ≤32）、`返回在函数外`、
`跳出在循环外`、`循环外引用 轮`、`跳转跨越块边界`、`函数未定义: <名>`、`函数嵌套`（函数不得嵌套定义）、
`类型错`（静态可判：串入条件 / 串做算术 / 串做大小比较）、`表长度非法`（1..4096）、`名字过长`（>63 字符）、`文件过大`（源码 >64KB）、
`程序过大`（字节码 >32KB）、`字符串转义非法`、`插值非法`、
`字符串未闭合`、`非法数字`、`非法字符`。

**运行期**（中止 + 行号：`op 中止 <名> 第 <行> 行: <词>`）：
沿用现词族 `变量无值 / 结果无值 / 区域不存在 / 模板不存在 / 非开关型 / 无画面 / 视觉错 / 槽占用 / 未按下 /
条件不成立 / 条件中止 / 跳转超限 / 终止`；新增 `类型错`、`下标越界`、`字符串池满`、`调用超深`；
核心验证器拒收词：`程序非法`（整条操作拒收，不动其余）。

## §7 文法（EBNF 摘要）

```
file    := { stmt } ;
stmt    := action | assign | if | loop | loopfor | while | until | ctl | term | ret
         | toast | hl | box | fn | callstmt | table | jmp ;
action  := "点按" e e [e] opt* | "滑动" e e e e opt* | "等待" e | "按下" e e | "弹起" ;
assign  := id [ "[" e "]" ] "=" e ;
if      := "如果" e block [ "否则" block ] ;
loop    := "循环" ( "无限" block | opt block | e block ) ;
loopfor := "循环" id "从" e "到" e block ;
while   := ( "当" | "直到" ) e block ;
ctl     := ( "跳出" | "继续" ) [ int ] ; term := "终止" [ "中止" ] ;
ret     := "返回" [ e ] ; toast := "提示" e opt* ; hl := "框区域" str opt* ;
box     := "框矩形" e e e e opt* ; fn := "函数" id "(" [ id { "," id } ] ")" block ;
callstmt:= call ; table := "表" id [ "[" int "]" ] ;                    // call 同表达式位（语句位结果弃）
jmp     := "跳转" ( "第" int "行" | int | "结束" ) ;                  // `第12行` = 单标识符形态；`跳转 0` 拒（用 `跳转 结束`）
opt     := id "=" e ;        // 键 = 语境词（支持集见 §3）
call    := ( id | 内建名 | 视觉名 ) "(" [ arg { "," arg } ] ")" ;
arg     := e | optkey "=" e ;
block   := "{" { stmt } "}" ;        // 表达式不跨行（含实参）；块 `{` 前允许换行
e       := or ; or := and {"||" and} ; and := cmp {"&&" cmp} ; cmp := add [ ("=="|"!="|"<"|">"|"<="|">=") add ] ;
add     := mul {("+"|"-") mul} ; mul := unary {("*"|"/"|"%") unary} ;
unary   := ["-"|"!"] unary | prim ;
prim    := num | str | "真" | "假" | "轮" | call | id "[" e "]" | id | "(" e ")" ;
```

## §8 可视化子集（双视图单模锁定的判据）

- 机制：AST 是唯一真相。**块视图 = AST 的节点渲染**；"脚本 → 块"可切换的条件 = 程序中每个节点都有块实现。
  T6 落地把投影目标 = **步骤表模型**（23 类步骤 + 子条件链，= T5.1 迁移域）；**覆盖清单（T6 v1，随实现维护）**：
  点按 / 滑动 / 等待 / 按下 / 弹起 / 赋值（v5 表达式域）/ 如果·否则（判定原子 + 且·或·取反 DNF 子条件）/ 循环×4（次数 / 时长 /
  无限 / 直到）/ 跳出·继续（层数）/ 终止 / 提示 / 框区域 / 框矩形 —— 步骤级节点与字段域**全量覆盖**。
- 仅脚本（出现即给「第 N 行: 原因」，留在脚本模式）：
  `跳转`（兼容语法）；T6 v1 未覆盖（脚本侧已全量可用，块侧按批扩展）：函数 / 表 / 返回 / 调用语句、`当` 循环、for 计数循环；
  以及超出步骤字段域的写法——负数字面量（与变量编码冲突）、复合表达式（% / 字符串 / 比较链，赋值步除外）、
  自定义变量 >16、变量名 >15 字、**注释**、子条件 >4、嵌套 >8。
- "块 → 脚本"恒可（规范打印）：每语句一行、块体缩进 4 空格、操作数空格分隔、命名参数按固定顺序输出；
  缺省参数补显、显式默认折叠（`阈值=8` / `停1=0` …）——块视图保存 = 输出规范形态。
- 注释口径 [r8]：脚本模式保存 = 文本原样（注释全程保留）；块视图投影**拒绝含注释脚本**（块侧无法承载注释，
  防静默丢失；提示先删注释或留在脚本模式）。`#模式` 侧线按 §1 归一。
- 投影自检（宁缺毋滥）：`VtToSteps.project` 内置**固定点校验**——投影产物再走一遍全链翻译必须与首次逐字一致，
  否则拒绝并给原因。实测判据：out-mig 8 件 + out-mig-zt 42 件真实迁移产物**逐字往返全绿**（`VtToStepsCheck` 66 例
  + 设备测试台「T6 双视图」核）；历次验收负例夹具（ztc3 / ztc12 / ztd4 / zte2）保持拒绝。
- 进阶（[后续]，见 §11）：规范格式双向实时同编；块视图节点覆盖扩至全语言。

## §9 语义重写规则（迁移/编译共用；条件档位 → 结构）

现有"条件/视觉步 四档（继续/跳过下一步/跳到第N步/中止）"在结构化语言中的等价重写（**迁移器与编译器同用**）：

| 档位（该侧） | 重写 |
|---|---|
| 继续 | 该侧空块：`如果 c { } 否则 { … }` 里对应侧为空 |
| 跳过下一步 | **吸收下一步**：跳过侧 = 假 ⇔ `如果 c { 下一步 }`；跳过侧 = 真 ⇔ `如果 !c { 下一步 }`（下一步被吸收进块体，原位置移除） |
| 跳到第 N 步 | 编译期展开力所能及时展开；不可展开 → 该侧 `跳转 第N行`（兼容语句，编译期校验不得进/跨块） |
| 中止 | `终止 中止`（词=成立/不成立侧对应现词 `条件中止`/`条件不成立`/`未命中`） |

（被短路的子条件不求值、`跳过`步不求值等现行细节，编译期以"不求值"等价展开保证。）
